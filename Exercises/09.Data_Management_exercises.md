# Bài Tập Tuần 9: Quản Lý Dữ Liệu — UPDATE, DELETE, Transaction & VIEW

> **Yêu cầu:** Trước khi làm bài tập, hãy chạy phần SETUP trong file `09.Data_Management_examples.sql` để có dữ liệu mẫu sạch.
>
> **Dữ liệu dùng — 5 bảng:**
> - `nhan_vien`: 12 nhân viên, 4 phòng ban, có `tinh_trang`, `ngay_vao`, `ngay_sinh`
> - `khach_hang`: 6 khách — id=6 không có đơn hàng
> - `san_pham`: 8 sản phẩm, có `ma_sp`, `ten_sp`, `so_luong_ton`
> - `don_hang`: 12 đơn — DH006 có `trang_thai='huy'`, DH011 `='cho_xu_ly'`
> - `chi_tiet_don_hang`: 20 dòng chi tiết
>
> ⚠️ **Quy tắc an toàn khi làm bài tập:**
> - **Luôn bọc UPDATE và DELETE trong `BEGIN` / `ROLLBACK`** khi luyện tập
> - **Chạy SELECT trước** để xem sẽ có bao nhiêu hàng bị ảnh hưởng
> - Chỉ dùng `COMMIT` khi chủ động muốn lưu thay đổi vĩnh viễn
> - Nếu lỡ COMMIT sai → chạy lại phần SETUP để reset dữ liệu

## Phần 1 — UPDATE Cơ Bản

**Bài 1.1:** Cập nhật email cho nhân viên id=5 (Hoàng Thị Dung) thành `dung.hoang@company.com`. Dùng quy trình 3 bước: SELECT trước → UPDATE → SELECT kiểm tra.

<details>
<summary>✅ Đáp án</summary>

```sql
-- Bước 1: Xem trước
SELECT id, ho_ten, email FROM nhan_vien WHERE id = 5;

-- Bước 2: Cập nhật (bọc trong transaction để an toàn)
BEGIN;
UPDATE nhan_vien
SET email = 'dung.hoang@company.com'
WHERE id = 5;

-- Bước 3: Kiểm tra
SELECT id, ho_ten, email FROM nhan_vien WHERE id = 5;

COMMIT;  -- Hoặc ROLLBACK nếu muốn hủy
```

</details>

---

**Bài 1.2:** Tăng lương **5%** cho tất cả nhân viên phòng **Nhân sự** đang làm việc (`tinh_trang = 'dang_lam'`). Hiển thị lương cũ và lương mới trong bước SELECT xem trước.

<details>
<summary>💡 Gợi ý</summary>

Bước SELECT xem trước: `SELECT ho_ten, luong, luong * 1.05 AS luong_moi FROM nhan_vien WHERE ...`

</details>

<details>
<summary>✅ Đáp án</summary>

```sql
-- Bước 1: Xem trước
SELECT ho_ten, luong, luong * 1.05 AS luong_sau_tang
FROM nhan_vien
WHERE phong_ban = 'Nhân sự' AND tinh_trang = 'dang_lam';

-- Bước 2: Thực hiện
BEGIN;
UPDATE nhan_vien
SET luong = luong * 1.05
WHERE phong_ban = 'Nhân sự' AND tinh_trang = 'dang_lam';

-- Bước 3: Kiểm tra
SELECT ho_ten, luong FROM nhan_vien WHERE phong_ban = 'Nhân sự';

COMMIT;
```

</details>

---

**Bài 1.3:** Cập nhật `trang_thai` thành `'da_giao'` cho tất cả đơn hàng `'hoan_thanh'` có ngày đặt **trước** `'2024-04-01'`. Xem trước có bao nhiêu đơn sẽ bị cập nhật.

<details>
<summary>✅ Đáp án</summary>

```sql
-- Xem trước
SELECT ma_don_hang, ngay_dat, trang_thai
FROM don_hang
WHERE trang_thai = 'hoan_thanh' AND ngay_dat < '2024-04-01';

-- Cập nhật
BEGIN;
UPDATE don_hang
SET trang_thai = 'da_giao'
WHERE trang_thai = 'hoan_thanh' AND ngay_dat < '2024-04-01';

SELECT ma_don_hang, ngay_dat, trang_thai FROM don_hang ORDER BY ngay_dat;
COMMIT;
```

</details>

---

**Bài 1.4:** Dùng `CASE WHEN` để tăng lương nhân viên theo cấp bậc thâm niên:
- Thâm niên >= 5 năm → tăng 12%
- Thâm niên 3–5 năm → tăng 8%
- Thâm niên < 3 năm → tăng 5%

Chỉ áp dụng cho nhân viên đang làm việc. Xem trước kết quả trước khi UPDATE.

<details>
<summary>💡 Gợi ý</summary>

Dùng `EXTRACT(YEAR FROM AGE(CURRENT_DATE, ngay_vao))` để tính thâm niên trong phần `CASE WHEN`.

</details>

<details>
<summary>✅ Đáp án</summary>

```sql
-- Xem trước
SELECT
    ho_ten,
    ngay_vao,
    EXTRACT(YEAR FROM AGE(CURRENT_DATE, ngay_vao))::INTEGER AS tham_nien,
    luong,
    luong * CASE
        WHEN EXTRACT(YEAR FROM AGE(CURRENT_DATE, ngay_vao)) >= 5 THEN 1.12
        WHEN EXTRACT(YEAR FROM AGE(CURRENT_DATE, ngay_vao)) >= 3 THEN 1.08
        ELSE 1.05
    END::NUMERIC(12,0) AS luong_moi
FROM nhan_vien
WHERE tinh_trang = 'dang_lam';

-- Thực hiện
BEGIN;
UPDATE nhan_vien
SET luong = (luong * CASE
    WHEN EXTRACT(YEAR FROM AGE(CURRENT_DATE, ngay_vao)) >= 5 THEN 1.12
    WHEN EXTRACT(YEAR FROM AGE(CURRENT_DATE, ngay_vao)) >= 3 THEN 1.08
    ELSE 1.05
END)::NUMERIC(12,0)
WHERE tinh_trang = 'dang_lam';

SELECT ho_ten, luong FROM nhan_vien WHERE tinh_trang = 'dang_lam' ORDER BY luong DESC;
ROLLBACK;  -- Hủy để giữ dữ liệu sạch cho bài tiếp theo
```

</details>

## Phần 2 — DELETE & Thứ Tự Xóa

**Bài 2.1:** Xóa nhân viên có `tinh_trang = 'nghi_viec'`. Nhớ kiểm tra bằng SELECT trước.

> **Chú ý:** Bọc trong `BEGIN` / `ROLLBACK` để an toàn, vì bài sau cần dữ liệu nhân viên.

<details>
<summary>✅ Đáp án</summary>

```sql
-- Xem trước
SELECT id, ho_ten, tinh_trang FROM nhan_vien WHERE tinh_trang = 'nghi_viec';

BEGIN;
DELETE FROM nhan_vien WHERE tinh_trang = 'nghi_viec';

SELECT COUNT(*) AS so_nv_con_lai FROM nhan_vien;
SELECT tinh_trang, COUNT(*) FROM nhan_vien GROUP BY tinh_trang;

ROLLBACK;  -- Giữ lại để không ảnh hưởng bài khác
```

</details>

---

**Bài 2.2:** Xóa **hoàn toàn** đơn hàng `'DH006'` (đơn bị hủy) khỏi cả hai bảng. Nhớ xóa bảng con (`chi_tiet_don_hang`) trước, bảng cha (`don_hang`) sau.

<details>
<summary>✅ Đáp án</summary>

```sql
-- Xem trước: chi tiết đơn DH006
SELECT ct.*
FROM chi_tiet_don_hang ct
JOIN don_hang dh ON ct.don_hang_id = dh.id
WHERE dh.ma_don_hang = 'DH006';

BEGIN;

-- Bước 1: Xóa bảng con trước
DELETE FROM chi_tiet_don_hang
WHERE don_hang_id = (SELECT id FROM don_hang WHERE ma_don_hang = 'DH006');

-- Bước 2: Xóa bảng cha
DELETE FROM don_hang WHERE ma_don_hang = 'DH006';

-- Kiểm tra
SELECT COUNT(*) AS so_don FROM don_hang;
SELECT COUNT(*) AS so_chi_tiet FROM chi_tiet_don_hang;

COMMIT;
```

</details>

---

**Bài 2.3:** Tại sao câu lệnh sau bị lỗi? Giải thích và sửa lại.

```sql
-- Tại sao lệnh này bị lỗi?
DELETE FROM don_hang WHERE trang_thai = 'huy';
```

<details>
<summary>✅ Giải thích & Đáp án</summary>

**Lý do lỗi:** Bảng `chi_tiet_don_hang` có khóa ngoại (`REFERENCES don_hang(id)`). Khi cố xóa một đơn hàng, PostgreSQL báo lỗi:
```
ERROR: update or delete on table "don_hang" violates foreign key constraint
"chi_tiet_don_hang_don_hang_id_fkey" on table "chi_tiet_don_hang"
```

**Sửa lại — xóa bảng con trước:**

```sql
BEGIN;

DELETE FROM chi_tiet_don_hang
WHERE don_hang_id IN (
    SELECT id FROM don_hang WHERE trang_thai = 'huy'
);

DELETE FROM don_hang WHERE trang_thai = 'huy';

COMMIT;
```

</details>

## Phần 3 — Transaction

**Bài 3.1:** Dùng Transaction để thực hành **an toàn**:
1. `BEGIN`
2. Tăng lương tất cả nhân viên lên 20%
3. `SELECT` kiểm tra lương trung bình
4. `ROLLBACK` — hủy bỏ (đây chỉ là luyện tập!)

Mô tả kết quả bạn thấy sau mỗi bước.

<details>
<summary>✅ Đáp án</summary>

```sql
-- Trước transaction
SELECT AVG(luong)::NUMERIC(12,0) AS luong_tb_truoc FROM nhan_vien;

BEGIN;

UPDATE nhan_vien SET luong = luong * 1.20;

-- Sau UPDATE (trong transaction)
SELECT AVG(luong)::NUMERIC(12,0) AS luong_tb_sau_update FROM nhan_vien;
-- Thấy lương đã tăng 20%

ROLLBACK;

-- Sau ROLLBACK
SELECT AVG(luong)::NUMERIC(12,0) AS luong_tb_sau_rollback FROM nhan_vien;
-- Lương trở về giá trị ban đầu ✅
```

</details>

---

**Bài 3.2:** Dùng SAVEPOINT để tăng lương theo 2 giai đoạn:
- Giai đoạn 1: Tăng lương phòng IT thêm 10%
- Tạo SAVEPOINT
- Giai đoạn 2: Tăng lương phòng Kế toán thêm 8%
- Phát hiện nhập nhầm → ROLLBACK về SAVEPOINT
- Sửa lại Kế toán thêm 5%
- COMMIT

<details>
<summary>✅ Đáp án</summary>

```sql
-- Ghi nhận lương ban đầu
SELECT phong_ban, AVG(luong)::NUMERIC(12,0) AS luong_tb
FROM nhan_vien WHERE tinh_trang = 'dang_lam'
GROUP BY phong_ban ORDER BY phong_ban;

BEGIN;

-- Giai đoạn 1: Tăng IT
UPDATE nhan_vien
SET luong = luong * 1.10
WHERE phong_ban = 'IT' AND tinh_trang = 'dang_lam';

SAVEPOINT sau_tang_IT;  -- Tạo điểm lưu

-- Giai đoạn 2 (nhầm)
UPDATE nhan_vien
SET luong = luong * 1.80    -- Nhầm! Đáng lẽ 1.05
WHERE phong_ban = 'Kế toán' AND tinh_trang = 'dang_lam';

-- Kiểm tra thấy sai
SELECT ho_ten, luong FROM nhan_vien WHERE phong_ban = 'Kế toán';

-- Hủy chỉ phần Kế toán
ROLLBACK TO SAVEPOINT sau_tang_IT;

-- Làm lại đúng
UPDATE nhan_vien
SET luong = luong * 1.05
WHERE phong_ban = 'Kế toán' AND tinh_trang = 'dang_lam';

-- Kiểm tra tổng thể
SELECT phong_ban, AVG(luong)::NUMERIC(12,0) AS luong_tb
FROM nhan_vien WHERE tinh_trang = 'dang_lam'
GROUP BY phong_ban ORDER BY phong_ban;

COMMIT;
```

</details>

## Phần 4 — VIEW

**Bài 4.1:** Tạo view `v_san_pham_con_hang` hiển thị các sản phẩm còn tồn kho (`so_luong_ton > 0`), gồm: `id`, `ten_sp`, `danh_muc`, `gia`, `so_luong_ton`, và cột `gia_tri_ton_kho` (= gia × so_luong_ton).

<details>
<summary>✅ Đáp án</summary>

```sql
CREATE OR REPLACE VIEW v_san_pham_con_hang AS
SELECT
    id,
    ten_sp,
    danh_muc,
    gia,
    so_luong_ton,
    gia * so_luong_ton AS gia_tri_ton_kho
FROM san_pham
WHERE so_luong_ton > 0
ORDER BY gia_tri_ton_kho DESC;

-- Dùng view
SELECT * FROM v_san_pham_con_hang;

-- Thống kê từ view
SELECT danh_muc, SUM(gia_tri_ton_kho) AS tong_gia_tri
FROM v_san_pham_con_hang
GROUP BY danh_muc ORDER BY tong_gia_tri DESC;
```

</details>

**Bài 4.2:** Tạo view `v_bao_cao_nhan_vien` hiển thị đầy đủ thông tin nhân viên đang làm việc:
- `ho_ten`, `phong_ban`, `luong`
- `nam_tham_nien` (số năm từ ngày vào)
- `phan_loai_luong` ('Cao' / 'Trung bình' / 'Thấp' theo ngưỡng tự chọn)
- `email_hien_thi` (dùng `COALESCE` để hiển thị email hoặc 'Chưa có')

<details>
<summary>✅ Đáp án</summary>

```sql
CREATE OR REPLACE VIEW v_bao_cao_nhan_vien AS
SELECT
    ho_ten,
    phong_ban,
    luong,
    EXTRACT(YEAR FROM AGE(CURRENT_DATE, ngay_vao))::INTEGER AS nam_tham_nien,
    CASE
        WHEN luong >= 22000000 THEN 'Cao'
        WHEN luong >= 17000000 THEN 'Trung bình'
        ELSE                        'Thấp'
    END AS phan_loai_luong,
    COALESCE(email, 'Chưa có') AS email_hien_thi
FROM nhan_vien
WHERE tinh_trang = 'dang_lam'
ORDER BY luong DESC;

SELECT * FROM v_bao_cao_nhan_vien;
```

</details>

**Bài 4.3:** Dùng view `v_bao_cao_nhan_vien` (bài 4.2) để trả lời các câu hỏi sau — **không** được JOIN hay truy vấn trực tiếp vào bảng `nhan_vien`:

a) Phòng ban nào có lương trung bình cao nhất?
b) Có bao nhiêu nhân viên thuộc từng nhóm phân loại lương?
c) Ai là nhân viên có thâm niên lâu nhất đang làm việc?

<details>
<summary>✅ Đáp án</summary>

```sql
-- a) Phòng ban lương TB cao nhất
SELECT phong_ban, AVG(luong)::NUMERIC(12,0) AS luong_tb
FROM v_bao_cao_nhan_vien
GROUP BY phong_ban
ORDER BY luong_tb DESC
LIMIT 1;

-- b) Số nhân viên theo nhóm lương
SELECT phan_loai_luong, COUNT(*) AS so_nhan_vien
FROM v_bao_cao_nhan_vien
GROUP BY phan_loai_luong
ORDER BY so_nhan_vien DESC;

-- c) Thâm niên lâu nhất
SELECT ho_ten, phong_ban, nam_tham_nien
FROM v_bao_cao_nhan_vien
ORDER BY nam_tham_nien DESC
LIMIT 1;
```

</details>

**Bài 4.4:** Tạo view `v_doanh_so_nhan_vien` thống kê doanh số của từng nhân viên:
- `ho_ten` (nhân viên), `phong_ban`
- `so_don_phu_trach` (số đơn họ phụ trách, kể cả đơn hủy)
- `so_don_hoan_thanh` (chỉ đơn không hủy)
- `tong_doanh_so` (tổng tiền đơn không hủy)

Sau khi tạo view, tìm top 3 nhân viên có doanh số cao nhất.

<details>
<summary>✅ Đáp án</summary>

```sql
CREATE OR REPLACE VIEW v_doanh_so_nhan_vien AS
SELECT
    nv.id,
    nv.ho_ten,
    nv.phong_ban,
    COUNT(dh.id)                                              AS so_don_phu_trach,
    SUM(CASE WHEN dh.trang_thai != 'huy' THEN 1 ELSE 0 END)  AS so_don_hoan_thanh,
    COALESCE(SUM(CASE WHEN dh.trang_thai != 'huy'
                      THEN dh.tong_tien END), 0)              AS tong_doanh_so
FROM nhan_vien nv
LEFT JOIN don_hang dh ON nv.id = dh.nhan_vien_id
GROUP BY nv.id, nv.ho_ten, nv.phong_ban;

-- Dùng view
SELECT * FROM v_doanh_so_nhan_vien ORDER BY tong_doanh_so DESC;

-- Top 3
SELECT ho_ten, phong_ban, so_don_hoan_thanh, tong_doanh_so
FROM v_doanh_so_nhan_vien
ORDER BY tong_doanh_so DESC
LIMIT 3;
```

</details>

## Phần 5 — ALTER TABLE & Kết Hợp

**Bài 5.1:** Thêm cột `hang_khach_hang VARCHAR(10)` vào bảng `khach_hang`. Sau đó cập nhật giá trị cho cột này dựa trên tổng chi tiêu (dùng view `v_thong_ke_khach_hang` nếu đã tạo, hoặc subquery):
- Tổng chi tiêu >= 10 triệu → `'Vang'`
- Tổng chi tiêu >= 1 triệu → `'Bac'`
- Còn lại → `'Dong'`

<details>
<summary>✅ Đáp án</summary>

```sql
-- Bước 1: Thêm cột
ALTER TABLE khach_hang
ADD COLUMN hang_khach_hang VARCHAR(10);

-- Bước 2: Cập nhật dựa trên subquery
UPDATE khach_hang
SET hang_khach_hang = CASE
    WHEN (
        SELECT COALESCE(SUM(dh.tong_tien), 0)
        FROM don_hang dh
        WHERE dh.khach_hang_id = khach_hang.id
          AND dh.trang_thai != 'huy'
    ) >= 10000000 THEN 'Vang'
    WHEN (
        SELECT COALESCE(SUM(dh.tong_tien), 0)
        FROM don_hang dh
        WHERE dh.khach_hang_id = khach_hang.id
          AND dh.trang_thai != 'huy'
    ) >= 1000000  THEN 'Bac'
    ELSE               'Dong'
END;

-- Kiểm tra kết quả
SELECT id, ho_ten, hang_khach_hang FROM khach_hang ORDER BY hang_khach_hang;
```

</details>

---

**Bài 5.2 (Thử thách):** Viết một chuỗi thao tác hoàn chỉnh trong Transaction:

1. `BEGIN`
2. Thêm cột `trang_thai_moi VARCHAR(20)` vào bảng `don_hang`
3. Cập nhật `trang_thai_moi`:
   - Đơn `'hoan_thanh'` ngày > 30 ngày trước → `'da_giao'`
   - Đơn `'hoan_thanh'` trong 30 ngày → `'dang_giao'`
   - Đơn `'huy'` → `'da_huy'`
   - Đơn `'cho_xu_ly'` → `'cho_xu_ly'`
4. Kiểm tra kết quả (`SELECT ma_don_hang, trang_thai, trang_thai_moi`)
5. `COMMIT`

<details>
<summary>✅ Đáp án</summary>

```sql
BEGIN;

-- Thêm cột
ALTER TABLE don_hang
ADD COLUMN trang_thai_moi VARCHAR(20);

-- Cập nhật theo điều kiện
UPDATE don_hang
SET trang_thai_moi = CASE
    WHEN trang_thai = 'hoan_thanh' AND ngay_dat < CURRENT_DATE - INTERVAL '30 days'
         THEN 'da_giao'
    WHEN trang_thai = 'hoan_thanh' AND ngay_dat >= CURRENT_DATE - INTERVAL '30 days'
         THEN 'dang_giao'
    WHEN trang_thai = 'huy'        THEN 'da_huy'
    ELSE trang_thai
END;

-- Kiểm tra
SELECT ma_don_hang, ngay_dat, trang_thai, trang_thai_moi
FROM don_hang
ORDER BY ngay_dat;

-- Phân bố trạng thái mới
SELECT trang_thai_moi, COUNT(*) AS so_don
FROM don_hang
GROUP BY trang_thai_moi
ORDER BY so_don DESC;

COMMIT;
```

</details>
