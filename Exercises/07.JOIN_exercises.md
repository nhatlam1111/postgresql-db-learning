# Bài Tập Tuần 7: Kết Nối Nhiều Bảng — JOIN

> **Yêu cầu:** Trước khi làm bài tập, hãy chạy phần SETUP trong file `07.JOIN_examples.sql` để có dữ liệu mẫu.
>
> **Dữ liệu dùng — 5 bảng liên kết:**
> - `khach_hang`: 6 khách (id 1–6), cột `id`, `ho_ten`, `dien_thoai`, `email`, `thanh_pho`
> - `nhan_vien`: 4 nhân viên KD, cột `id`, `ho_ten`, `phong_ban`, `tinh_trang`
> - `san_pham`: 8 sản phẩm (id 1–8), cột `id`, `ten_san_pham`, `danh_muc`, `gia`
> - `don_hang`: 12 đơn (DH001–DH012), cột `id`, `ma_don_hang`, `khach_hang_id`, `nhan_vien_id`, `ngay_dat`, `trang_thai`
> - `chi_tiet_don_hang`: 20 dòng chi tiết, cột `id`, `don_hang_id`, `san_pham_id`, `so_luong`, `don_gia`
>
> **Lưu ý:**
> - Khách hàng id=6 (Ngô Thị Phương) **không có đơn hàng** — dùng để luyện LEFT JOIN
> - Sản phẩm id=8 (Sách PostgreSQL) **không có trong đơn hàng nào** — dùng để luyện LEFT JOIN
> - Đơn DH006 có `trang_thai = 'huy'` — nhớ lọc khi tính doanh thu

## Phần 1 — Cơ Bản

**Bài 1.1:** Xem tất cả đơn hàng kèm **tên khách hàng**. Hiển thị: `ma_don_hang`, `ho_ten` (khách), `ngay_dat`, `trang_thai`. Sắp xếp theo ngày đặt giảm dần.

<details>
<summary>💡 Gợi ý</summary>

Dùng `JOIN khach_hang ON don_hang.khach_hang_id = khach_hang.id`

</details>

<details>
<summary>✅ Đáp án</summary>

```sql
SELECT
    dh.ma_don_hang,
    kh.ho_ten       AS ten_khach,
    dh.ngay_dat,
    dh.trang_thai
FROM don_hang dh
JOIN khach_hang kh ON dh.khach_hang_id = kh.id
ORDER BY dh.ngay_dat DESC;
```

</details>

---

**Bài 1.2:** Xem chi tiết sản phẩm trong tất cả đơn hàng. Hiển thị: `ma_don_hang`, `ten_san_pham`, `so_luong`, `don_gia`. Sắp theo `ma_don_hang`.

<details>
<summary>✅ Đáp án</summary>

```sql
SELECT
    dh.ma_don_hang,
    sp.ten_san_pham,
    ct.so_luong,
    ct.don_gia
FROM chi_tiet_don_hang ct
JOIN don_hang dh    ON ct.don_hang_id = dh.id
JOIN san_pham sp    ON ct.san_pham_id = sp.id
ORDER BY dh.ma_don_hang;
```

</details>

---

**Bài 1.3:** Tìm tất cả **khách hàng chưa có đơn hàng nào**. Hiển thị: `ho_ten`, `dien_thoai`, `thanh_pho`.

<details>
<summary>💡 Gợi ý</summary>

Dùng LEFT JOIN và lọc `WHERE don_hang.id IS NULL`

</details>

<details>
<summary>✅ Đáp án</summary>

```sql
SELECT kh.ho_ten, kh.dien_thoai, kh.thanh_pho
FROM khach_hang kh
LEFT JOIN don_hang dh ON kh.id = dh.khach_hang_id
WHERE dh.id IS NULL;
```

Kết quả mong đợi: Ngô Thị Phương

</details>

---

**Bài 1.4:** Xem đơn hàng kèm cả **tên khách hàng** và **tên nhân viên phụ trách**. Hiển thị: `ma_don_hang`, `ngay_dat`, `ten_khach`, `nhan_vien_phu_trach`.

<details>
<summary>✅ Đáp án</summary>

```sql
SELECT
    dh.ma_don_hang,
    dh.ngay_dat,
    kh.ho_ten       AS ten_khach,
    nv.ho_ten       AS nhan_vien_phu_trach
FROM don_hang dh
JOIN khach_hang kh  ON dh.khach_hang_id = kh.id
JOIN nhan_vien nv   ON dh.nhan_vien_id = nv.id
ORDER BY dh.ngay_dat;
```

</details>

---

**Bài 1.5:** Tìm tất cả **sản phẩm chưa từng có trong đơn hàng nào**. Hiển thị: `ten_san_pham`, `danh_muc`, `gia`.

<details>
<summary>✅ Đáp án</summary>

```sql
SELECT sp.ten_san_pham, sp.danh_muc, sp.gia
FROM san_pham sp
LEFT JOIN chi_tiet_don_hang ct ON sp.id = ct.san_pham_id
WHERE ct.id IS NULL;
```

Kết quả mong đợi: Sách PostgreSQL cơ bản

</details>

## Phần 2 — Trung Bình

**Bài 2.1:** Tính **tổng tiền từng đơn hàng** (chỉ đơn đã hoàn thành). Hiển thị: `ma_don_hang`, `ten_khach`, `ngay_dat`, `tong_tien_don`. Sắp xếp theo tổng tiền giảm dần.

<details>
<summary>💡 Gợi ý</summary>

Cần JOIN 3 bảng: `don_hang`, `khach_hang`, `chi_tiet_don_hang`. Dùng `SUM(so_luong * don_gia)` và `GROUP BY`.

</details>

<details>
<summary>✅ Đáp án</summary>

```sql
SELECT
    dh.ma_don_hang,
    kh.ho_ten                           AS ten_khach,
    dh.ngay_dat,
    SUM(ct.so_luong * ct.don_gia)       AS tong_tien_don
FROM don_hang dh
JOIN khach_hang kh          ON dh.khach_hang_id = kh.id
JOIN chi_tiet_don_hang ct   ON dh.id = ct.don_hang_id
WHERE dh.trang_thai = 'hoan_thanh'
GROUP BY dh.id, dh.ma_don_hang, kh.ho_ten, dh.ngay_dat
ORDER BY tong_tien_don DESC;
```

</details>

---

**Bài 2.2:** Tính **tổng chi tiêu của mỗi khách hàng** (chỉ đơn hoàn thành). Hiển thị: `ho_ten`, `so_don_hang`, `tong_chi_tieu`. Bao gồm cả khách chưa có đơn (hiển thị 0 hoặc NULL). Sắp theo tổng chi tiêu giảm dần.

<details>
<summary>💡 Gợi ý</summary>

Dùng LEFT JOIN để giữ khách chưa có đơn. Đặt điều kiện `trang_thai = 'hoan_thanh'` trong mệnh đề `ON` chứ không phải `WHERE`.

</details>

<details>
<summary>✅ Đáp án</summary>

```sql
SELECT
    kh.ho_ten,
    COUNT(DISTINCT dh.id)                       AS so_don_hang,
    COALESCE(SUM(ct.so_luong * ct.don_gia), 0)  AS tong_chi_tieu
FROM khach_hang kh
LEFT JOIN don_hang dh         ON kh.id = dh.khach_hang_id
                              AND dh.trang_thai = 'hoan_thanh'
LEFT JOIN chi_tiet_don_hang ct ON dh.id = ct.don_hang_id
GROUP BY kh.id, kh.ho_ten
ORDER BY tong_chi_tieu DESC;
```

</details>

---

**Bài 2.3:** Tìm **top 3 sản phẩm bán chạy nhất** (theo số lượng), chỉ tính đơn hoàn thành. Hiển thị: `ten_san_pham`, `danh_muc`, `tong_so_luong`, `tong_doanh_thu`.

<details>
<summary>✅ Đáp án</summary>

```sql
SELECT
    sp.ten_san_pham,
    sp.danh_muc,
    SUM(ct.so_luong)                    AS tong_so_luong,
    SUM(ct.so_luong * ct.don_gia)       AS tong_doanh_thu
FROM san_pham sp
JOIN chi_tiet_don_hang ct ON sp.id = ct.san_pham_id
JOIN don_hang dh          ON ct.don_hang_id = dh.id
WHERE dh.trang_thai = 'hoan_thanh'
GROUP BY sp.id, sp.ten_san_pham, sp.danh_muc
ORDER BY tong_so_luong DESC
LIMIT 3;
```

</details>

---

**Bài 2.4:** Thống kê **doanh thu theo nhân viên**, chỉ tính nhân viên đang làm và đơn hoàn thành. Hiển thị: `ho_ten`, `so_don`, `tong_doanh_thu`. Sắp theo doanh thu giảm dần.

<details>
<summary>✅ Đáp án</summary>

```sql
SELECT
    nv.ho_ten,
    COUNT(DISTINCT dh.id)               AS so_don,
    COALESCE(SUM(ct.so_luong * ct.don_gia), 0) AS tong_doanh_thu
FROM nhan_vien nv
LEFT JOIN don_hang dh         ON nv.id = dh.nhan_vien_id
                              AND dh.trang_thai = 'hoan_thanh'
LEFT JOIN chi_tiet_don_hang ct ON dh.id = ct.don_hang_id
WHERE nv.tinh_trang = 'dang_lam'
GROUP BY nv.id, nv.ho_ten
ORDER BY tong_doanh_thu DESC;
```

</details>

---

**Bài 2.5:** Thống kê **số đơn và doanh thu theo thành phố** khách hàng (chỉ đơn hoàn thành). Hiển thị: `thanh_pho`, `so_khach`, `so_don`, `tong_doanh_thu`.

<details>
<summary>✅ Đáp án</summary>

```sql
SELECT
    kh.thanh_pho,
    COUNT(DISTINCT kh.id)               AS so_khach,
    COUNT(DISTINCT dh.id)               AS so_don,
    SUM(ct.so_luong * ct.don_gia)       AS tong_doanh_thu
FROM khach_hang kh
JOIN don_hang dh            ON kh.id = dh.khach_hang_id
JOIN chi_tiet_don_hang ct   ON dh.id = ct.don_hang_id
WHERE dh.trang_thai = 'hoan_thanh'
GROUP BY kh.thanh_pho
ORDER BY tong_doanh_thu DESC;
```

</details>

## Phần 3 — Nâng Cao

**Bài 3.1:** Tạo **báo cáo đầy đủ theo danh mục sản phẩm** (chỉ đơn hoàn thành):
- Tên danh mục
- Số loại sản phẩm trong danh mục
- Tổng số lượng bán ra
- Tổng doanh thu
- Chỉ hiển thị danh mục có doanh thu trên 1 triệu

<details>
<summary>✅ Đáp án</summary>

```sql
SELECT
    sp.danh_muc,
    COUNT(DISTINCT sp.id)               AS so_loai_sp,
    SUM(ct.so_luong)                    AS tong_so_luong,
    SUM(ct.so_luong * ct.don_gia)       AS tong_doanh_thu
FROM san_pham sp
JOIN chi_tiet_don_hang ct ON sp.id = ct.san_pham_id
JOIN don_hang dh          ON ct.don_hang_id = dh.id
WHERE dh.trang_thai = 'hoan_thanh'
GROUP BY sp.danh_muc
HAVING SUM(ct.so_luong * ct.don_gia) > 1000000
ORDER BY tong_doanh_thu DESC;
```

</details>

---

**Bài 3.2:** Tìm **khách hàng mua hàng nhiều lần** (ít nhất 3 đơn hoàn thành). Hiển thị: `ho_ten`, `thanh_pho`, `so_don`, `tong_chi_tieu`.

<details>
<summary>💡 Gợi ý</summary>

Kết hợp JOIN + GROUP BY + HAVING COUNT(DISTINCT ...) >= 3

</details>

<details>
<summary>✅ Đáp án</summary>

```sql
SELECT
    kh.ho_ten,
    kh.thanh_pho,
    COUNT(DISTINCT dh.id)               AS so_don,
    SUM(ct.so_luong * ct.don_gia)       AS tong_chi_tieu
FROM khach_hang kh
JOIN don_hang dh            ON kh.id = dh.khach_hang_id
JOIN chi_tiet_don_hang ct   ON dh.id = ct.don_hang_id
WHERE dh.trang_thai = 'hoan_thanh'
GROUP BY kh.id, kh.ho_ten, kh.thanh_pho
HAVING COUNT(DISTINCT dh.id) >= 3
ORDER BY so_don DESC, tong_chi_tieu DESC;
```

</details>

---

**Bài 3.3:** Tìm **sản phẩm chưa bán** (không có trong bất kỳ đơn hoàn thành nào). Hiển thị: `ten_san_pham`, `danh_muc`, `gia`.

<details>
<summary>💡 Gợi ý</summary>

Dùng LEFT JOIN qua cả `chi_tiet_don_hang` lẫn `don_hang` (với điều kiện `trang_thai = 'hoan_thanh'` trong ON). Lọc `WHERE ct.id IS NULL`.

</details>

<details>
<summary>✅ Đáp án</summary>

```sql
SELECT sp.ten_san_pham, sp.danh_muc, sp.gia
FROM san_pham sp
LEFT JOIN chi_tiet_don_hang ct ON sp.id = ct.san_pham_id
LEFT JOIN don_hang dh          ON ct.don_hang_id = dh.id
                               AND dh.trang_thai = 'hoan_thanh'
WHERE dh.id IS NULL
ORDER BY sp.danh_muc, sp.ten_san_pham;
```

</details>

---

**Bài 3.4 — Thử thách:** Lập **bảng xếp hạng nhân viên kinh doanh** đầy đủ:
- Họ tên nhân viên
- Số đơn hàng hoàn thành phụ trách
- Tổng doanh thu mang về
- Giá trị đơn hàng trung bình
- Chỉ lấy nhân viên đang làm, và chỉ hiển thị người có ít nhất 1 đơn hoàn thành

<details>
<summary>💡 Gợi ý</summary>

JOIN 4 bảng: `nhan_vien`, `don_hang`, `chi_tiet_don_hang`. Nhớ GROUP BY đầy đủ và HAVING để lọc người có đơn.

</details>

<details>
<summary>✅ Đáp án</summary>

```sql
SELECT
    nv.ho_ten                                   AS nhan_vien,
    COUNT(DISTINCT dh.id)                       AS so_don_hoan_thanh,
    SUM(ct.so_luong * ct.don_gia)               AS tong_doanh_thu,
    ROUND(SUM(ct.so_luong * ct.don_gia)
          / COUNT(DISTINCT dh.id), 0)           AS gia_tri_don_tb
FROM nhan_vien nv
JOIN don_hang dh            ON nv.id = dh.nhan_vien_id
JOIN chi_tiet_don_hang ct   ON dh.id = ct.don_hang_id
WHERE nv.tinh_trang = 'dang_lam'
  AND dh.trang_thai = 'hoan_thanh'
GROUP BY nv.id, nv.ho_ten
HAVING COUNT(DISTINCT dh.id) >= 1
ORDER BY tong_doanh_thu DESC;
```

</details>

## Tổng Kết

| Kỹ năng | Đã thành thạo? |
|---|---|
| Giải thích tại sao cần tách bảng (vấn đề dữ liệu lặp) | ☐ |
| Phân biệt Primary Key và Foreign Key | ☐ |
| INNER JOIN — kết nối 2 bảng, chỉ lấy hàng khớp | ☐ |
| Dùng table alias để viết gọn | ☐ |
| Viết `bang.cot` khi có cột trùng tên | ☐ |
| LEFT JOIN — giữ tất cả từ bảng trái | ☐ |
| LEFT JOIN + IS NULL để tìm hàng "mồ côi" | ☐ |
| JOIN 3+ bảng | ☐ |
| Đặt điều kiện trong ON vs WHERE (khác nhau với LEFT JOIN) | ☐ |
| JOIN + GROUP BY + HAVING — báo cáo từ nhiều bảng | ☐ |
