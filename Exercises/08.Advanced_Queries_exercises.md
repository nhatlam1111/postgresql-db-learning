# Bài Tập Tuần 8: Truy Vấn Nâng Cao — Subquery, CASE WHEN & Hàm Xử Lý Dữ Liệu

> **Yêu cầu:** Trước khi làm bài tập, hãy chạy phần SETUP trong file `08.Advanced_Queries_examples.sql` để có dữ liệu mẫu.
>
> **Dữ liệu dùng — 5 bảng liên kết (cập nhật so với tuần 7):**
> - `nhan_vien`: 12 nhân viên, có thêm `ngay_sinh`, `ngay_vao`, `tinh_trang`, `nickname`, `email`
> - `khach_hang`: 6 khách (id 1–6) — khách id=6 (Ngô Thị Phương) không có đơn hàng
> - `san_pham`: 8 sản phẩm — id=8 (Sách PostgreSQL) không có trong đơn hàng nào
> - `don_hang`: 12 đơn (DH001–DH012) — DH006 có `trang_thai = 'huy'`
> - `chi_tiet_don_hang`: 21 dòng chi tiết
>
> **Lưu ý khi làm bài:**
> - Khi tính doanh thu, nhớ loại đơn hủy: `WHERE trang_thai != 'huy'` hoặc `CASE WHEN trang_thai != 'huy'`
> - Khi dùng `NOT IN`, luôn thêm `WHERE cot IS NOT NULL` vào subquery

## Phần 1 — Cơ Bản (Subquery)

**Bài 1.1:** Tìm tất cả nhân viên có lương **cao hơn** lương trung bình của toàn công ty. Hiển thị: `ho_ten`, `phong_ban`, `luong`. Sắp xếp theo lương giảm dần.

<details>
<summary>💡 Gợi ý</summary>

Dùng subquery trong WHERE: `WHERE luong > (SELECT AVG(luong) FROM nhan_vien)`

</details>

<details>
<summary>✅ Đáp án</summary>

```sql
SELECT ho_ten, phong_ban, luong
FROM nhan_vien
WHERE luong > (SELECT AVG(luong) FROM nhan_vien)
ORDER BY luong DESC;
```

</details>

---

**Bài 1.2:** Tìm sản phẩm có giá **bằng** giá cao nhất trong bảng. Hiển thị `ten_sp`, `danh_muc`, `gia`.

*(Lưu ý: không được dùng `ORDER BY gia DESC LIMIT 1` — hãy dùng subquery.)*

<details>
<summary>✅ Đáp án</summary>

```sql
SELECT ten_sp, danh_muc, gia
FROM san_pham
WHERE gia = (SELECT MAX(gia) FROM san_pham);
```

</details>

---

**Bài 1.3:** Tìm tất cả khách hàng **đã từng đặt ít nhất một đơn hàng**. Dùng subquery với `IN`. Hiển thị `ho_ten`, `thanh_pho`.

<details>
<summary>✅ Đáp án</summary>

```sql
SELECT ho_ten, thanh_pho
FROM khach_hang
WHERE id IN (
    SELECT DISTINCT khach_hang_id
    FROM don_hang
    WHERE khach_hang_id IS NOT NULL
);
```

</details>

---

**Bài 1.4:** Tìm khách hàng **chưa đặt hàng lần nào**. Dùng subquery với `NOT IN`.

<details>
<summary>⚠️ Lưu ý</summary>

Nhớ thêm `WHERE khach_hang_id IS NOT NULL` trong subquery để tránh bẫy NULL với `NOT IN`.

</details>

<details>
<summary>✅ Đáp án</summary>

```sql
SELECT ho_ten, thanh_pho
FROM khach_hang
WHERE id NOT IN (
    SELECT DISTINCT khach_hang_id
    FROM don_hang
    WHERE khach_hang_id IS NOT NULL
);
-- Kết quả: chỉ Ngô Thị Phương (id=6)
```

</details>

---

**Bài 1.5:** Tìm sản phẩm **chưa xuất hiện trong bất kỳ đơn hàng nào**. Hiển thị `ten_sp`, `danh_muc`, `gia`.

<details>
<summary>✅ Đáp án</summary>

```sql
SELECT ten_sp, danh_muc, gia
FROM san_pham
WHERE id NOT IN (
    SELECT DISTINCT san_pham_id
    FROM chi_tiet_don_hang
    WHERE san_pham_id IS NOT NULL
);
-- Kết quả: Sách PostgreSQL Căn Bản
```

</details>

## Phần 2 — Trung Bình (CASE WHEN & Subquery Trong FROM)

**Bài 2.1:** Thêm cột **phân loại lương** vào kết quả SELECT. Phân loại:
- Lương >= 22 triệu → `'Cao'`
- Lương >= 17 triệu → `'Trung bình'`
- Còn lại → `'Thấp'`

Hiển thị: `ho_ten`, `phong_ban`, `luong`, `phan_loai`.

<details>
<summary>✅ Đáp án</summary>

```sql
SELECT
    ho_ten,
    phong_ban,
    luong,
    CASE
        WHEN luong >= 22000000 THEN 'Cao'
        WHEN luong >= 17000000 THEN 'Trung bình'
        ELSE                        'Thấp'
    END AS phan_loai
FROM nhan_vien
ORDER BY luong DESC;
```

</details>

---

**Bài 2.2:** Phân loại sản phẩm theo giá:
- Giá >= 5 triệu → `'Premium'`
- Giá >= 500 nghìn → `'Trung bình'`
- Còn lại → `'Phổ thông'`

Hiển thị: `ten_sp`, `danh_muc`, `gia`, `phan_loai_gia`. Sắp xếp theo giá giảm dần.

<details>
<summary>✅ Đáp án</summary>

```sql
SELECT
    ten_sp,
    danh_muc,
    gia,
    CASE
        WHEN gia >= 5000000 THEN 'Premium'
        WHEN gia >= 500000  THEN 'Trung bình'
        ELSE                     'Phổ thông'
    END AS phan_loai_gia
FROM san_pham
ORDER BY gia DESC;
```

</details>

---

**Bài 2.3:** Đếm số nhân viên theo **nhóm lương** (dùng `CASE WHEN` trong `GROUP BY`):
- Nhóm Cao: >= 20 triệu
- Nhóm Trung bình: 15–20 triệu
- Nhóm Thấp: < 15 triệu

Hiển thị: tên nhóm, số nhân viên, lương trung bình của nhóm.

<details>
<summary>💡 Gợi ý</summary>

Dùng `CASE WHEN` trong cả `SELECT` lẫn `GROUP BY` — hai khối CASE WHEN phải giống nhau hoàn toàn.

</details>

<details>
<summary>✅ Đáp án</summary>

```sql
SELECT
    CASE
        WHEN luong >= 20000000 THEN 'Nhóm Cao (>= 20tr)'
        WHEN luong >= 15000000 THEN 'Nhóm Trung bình (15-20tr)'
        ELSE                        'Nhóm Thấp (< 15tr)'
    END AS nhom_luong,
    COUNT(*)                   AS so_nhan_vien,
    AVG(luong)::NUMERIC(12,0)  AS luong_tb
FROM nhan_vien
GROUP BY
    CASE
        WHEN luong >= 20000000 THEN 'Nhóm Cao (>= 20tr)'
        WHEN luong >= 15000000 THEN 'Nhóm Trung bình (15-20tr)'
        ELSE                        'Nhóm Thấp (< 15tr)'
    END
ORDER BY luong_tb DESC;
```

</details>

---

**Bài 2.4:** Tạo **báo cáo pivot ngang**: mỗi phòng ban trên 1 hàng, các cột thể hiện số nhân viên theo tình trạng (`dang_lam`, `nghi_phep`, `nghi_viec`).

<details>
<summary>💡 Gợi ý</summary>

Dùng kỹ thuật `SUM(CASE WHEN tinh_trang = 'dang_lam' THEN 1 ELSE 0 END)`.

</details>

<details>
<summary>✅ Đáp án</summary>

```sql
SELECT
    phong_ban,
    COUNT(*)                                                         AS tong_nv,
    SUM(CASE WHEN tinh_trang = 'dang_lam'  THEN 1 ELSE 0 END)      AS dang_lam,
    SUM(CASE WHEN tinh_trang = 'nghi_phep' THEN 1 ELSE 0 END)      AS nghi_phep,
    SUM(CASE WHEN tinh_trang = 'nghi_viec' THEN 1 ELSE 0 END)      AS nghi_viec
FROM nhan_vien
GROUP BY phong_ban
ORDER BY phong_ban;
```

</details>

---

**Bài 2.5:** Dùng **subquery trong FROM** để tìm phòng ban có lương trung bình **cao hơn** lương trung bình toàn công ty.

<details>
<summary>💡 Gợi ý</summary>

Bước 1: Tạo bảng tạm tính `AVG(luong)` theo từng `phong_ban`.
Bước 2: Lọc từ bảng tạm đó với điều kiện > lương TB toàn công ty (subquery thứ hai).

</details>

<details>
<summary>✅ Đáp án</summary>

```sql
SELECT phong_ban, avg_luong
FROM (
    SELECT
        phong_ban,
        AVG(luong)::NUMERIC(12,0) AS avg_luong
    FROM nhan_vien
    GROUP BY phong_ban
) AS bang_luong_pb
WHERE avg_luong > (SELECT AVG(luong) FROM nhan_vien)
ORDER BY avg_luong DESC;
```

</details>

## Phần 3 — Hàm Chuỗi & Ngày Tháng

**Bài 3.1:** Hiển thị họ tên nhân viên theo 3 dạng: chữ hoa, chữ thường, và độ dài tên. Chỉ lấy nhân viên có tên dài hơn 12 ký tự.

<details>
<summary>✅ Đáp án</summary>

```sql
SELECT
    ho_ten,
    UPPER(ho_ten)   AS ho_ten_hoa,
    LOWER(ho_ten)   AS ho_ten_thuong,
    LENGTH(ho_ten)  AS so_ky_tu
FROM nhan_vien
WHERE LENGTH(ho_ten) > 12
ORDER BY so_ky_tu DESC;
```

</details>

---

**Bài 3.2:** Lấy tên miền email của từng nhân viên (phần sau dấu `@`). Chỉ hiển thị nhân viên có email, sắp xếp theo tên miền.

<details>
<summary>💡 Gợi ý</summary>

Dùng `POSITION('@' IN email)` để tìm vị trí dấu @, rồi `SUBSTRING` để cắt.

</details>

<details>
<summary>✅ Đáp án</summary>

```sql
SELECT
    ho_ten,
    email,
    SUBSTRING(email, POSITION('@' IN email) + 1, LENGTH(email)) AS ten_mien
FROM nhan_vien
WHERE email IS NOT NULL
ORDER BY ten_mien, ho_ten;
```

</details>

---

**Bài 3.3:** Tạo cột `ma_nhan_vien` theo định dạng `NV-001`, `NV-002`... cho tất cả nhân viên.

<details>
<summary>✅ Đáp án</summary>

```sql
SELECT
    id,
    ho_ten,
    'NV-' || LPAD(id::TEXT, 3, '0') AS ma_nhan_vien
FROM nhan_vien
ORDER BY id;
```

</details>

---

**Bài 3.4:** Tính **tuổi** của từng nhân viên (tính theo năm). Hiển thị: `ho_ten`, `ngay_sinh`, `tuoi`. Sắp xếp từ trẻ nhất đến lớn tuổi nhất.

<details>
<summary>✅ Đáp án</summary>

```sql
SELECT
    ho_ten,
    ngay_sinh,
    EXTRACT(YEAR FROM AGE(CURRENT_DATE, ngay_sinh))::INTEGER AS tuoi
FROM nhan_vien
ORDER BY tuoi ASC;
```

</details>

---

**Bài 3.5:** Tính **thâm niên** (số năm làm việc) của từng nhân viên. Hiển thị `ho_ten`, `ngay_vao`, `nam_tham_nien`. Sắp xếp theo thâm niên giảm dần (lâu nhất đứng đầu).

<details>
<summary>✅ Đáp án</summary>

```sql
SELECT
    ho_ten,
    ngay_vao,
    EXTRACT(YEAR FROM AGE(CURRENT_DATE, ngay_vao))::INTEGER AS nam_tham_nien
FROM nhan_vien
ORDER BY nam_tham_nien DESC;
```

</details>

---

**Bài 3.6:** Thống kê số đơn hàng và doanh thu (không tính đơn hủy) **theo từng tháng**. Hiển thị: `nam`, `thang`, `so_don`, `doanh_thu`. Sắp xếp theo năm và tháng tăng dần.

<details>
<summary>✅ Đáp án</summary>

```sql
SELECT
    EXTRACT(YEAR  FROM ngay_dat)::INTEGER AS nam,
    EXTRACT(MONTH FROM ngay_dat)::INTEGER AS thang,
    COUNT(*)                              AS so_don,
    SUM(CASE WHEN trang_thai != 'huy' THEN tong_tien ELSE 0 END) AS doanh_thu
FROM don_hang
GROUP BY
    EXTRACT(YEAR  FROM ngay_dat),
    EXTRACT(MONTH FROM ngay_dat)
ORDER BY nam, thang;
```

</details>

---

**Bài 3.7:** Phân loại đơn hàng theo quý (Q1, Q2, Q3, Q4). Thống kê: tên quý, số đơn, doanh thu (không tính đơn hủy).

<details>
<summary>✅ Đáp án</summary>

```sql
SELECT
    CASE
        WHEN EXTRACT(MONTH FROM ngay_dat) BETWEEN 1 AND 3 THEN 'Q1'
        WHEN EXTRACT(MONTH FROM ngay_dat) BETWEEN 4 AND 6 THEN 'Q2'
        WHEN EXTRACT(MONTH FROM ngay_dat) BETWEEN 7 AND 9 THEN 'Q3'
        ELSE                                                    'Q4'
    END AS quy,
    COUNT(*) AS so_don,
    SUM(CASE WHEN trang_thai != 'huy' THEN tong_tien ELSE 0 END) AS doanh_thu
FROM don_hang
GROUP BY
    CASE
        WHEN EXTRACT(MONTH FROM ngay_dat) BETWEEN 1 AND 3 THEN 'Q1'
        WHEN EXTRACT(MONTH FROM ngay_dat) BETWEEN 4 AND 6 THEN 'Q2'
        WHEN EXTRACT(MONTH FROM ngay_dat) BETWEEN 7 AND 9 THEN 'Q3'
        ELSE                                                    'Q4'
    END
ORDER BY quy;
```

</details>

## Phần 4 — Nâng Cao (Kết Hợp Nhiều Kỹ Năng)

**Bài 4.1:** Viết báo cáo **tổng hợp nhân viên** gồm:
- `ho_ten` (nếu có nickname thì hiện nickname, không thì hiện họ tên)
- `phong_ban`
- `luong`
- `phan_loai_luong` (Cao / Trung bình / Thấp)
- `tinh_trang_vn` (chuyển 'dang_lam' → 'Đang làm', 'nghi_phep' → 'Nghỉ phép', 'nghi_viec' → 'Đã nghỉ')
- `email_hien_thi` (nếu không có email thì hiện 'Chưa cập nhật')

Chỉ lấy nhân viên **đang làm việc** (`dang_lam`).

<details>
<summary>✅ Đáp án</summary>

```sql
SELECT
    COALESCE(nickname, ho_ten)  AS ten_hien_thi,
    phong_ban,
    luong,
    CASE
        WHEN luong >= 22000000 THEN 'Cao'
        WHEN luong >= 17000000 THEN 'Trung bình'
        ELSE                        'Thấp'
    END AS phan_loai_luong,
    CASE tinh_trang
        WHEN 'dang_lam'  THEN 'Đang làm'
        WHEN 'nghi_phep' THEN 'Nghỉ phép'
        WHEN 'nghi_viec' THEN 'Đã nghỉ'
        ELSE tinh_trang
    END AS tinh_trang_vn,
    COALESCE(email, 'Chưa cập nhật') AS email_hien_thi
FROM nhan_vien
WHERE tinh_trang = 'dang_lam'
ORDER BY luong DESC;
```

</details>

---

**Bài 4.2:** Viết báo cáo **thống kê khách hàng** đầy đủ:
- Tên khách, thành phố
- Tổng số đơn (kể cả đơn hủy)
- Tổng tiền thực (chỉ đơn không hủy)
- Ngày đặt đơn gần nhất (định dạng `DD/MM/YYYY`)
- Phân loại: `'VIP'` (>= 10 triệu), `'Thường'` (1–10 triệu), `'Mới'` (> 0 nhưng < 1 triệu), `'Chưa mua'` (0 đơn)

Sắp xếp theo tổng tiền giảm dần.

<details>
<summary>💡 Gợi ý</summary>

Dùng `LEFT JOIN` để giữ cả khách chưa mua. Dùng `COALESCE(SUM(...), 0)` cho tổng tiền. Dùng `TO_CHAR(MAX(ngay_dat), 'DD/MM/YYYY')` cho ngày gần nhất.

</details>

<details>
<summary>✅ Đáp án</summary>

```sql
SELECT
    kh.ho_ten,
    kh.thanh_pho,
    COUNT(dh.id)                     AS tong_so_don,
    COALESCE(SUM(CASE WHEN dh.trang_thai != 'huy'
                      THEN dh.tong_tien ELSE 0 END), 0)     AS tong_tien_thuc,
    TO_CHAR(MAX(dh.ngay_dat), 'DD/MM/YYYY')                  AS don_gan_nhat,
    CASE
        WHEN COALESCE(SUM(CASE WHEN dh.trang_thai != 'huy'
                               THEN dh.tong_tien ELSE 0 END), 0) >= 10000000 THEN 'VIP'
        WHEN COALESCE(SUM(CASE WHEN dh.trang_thai != 'huy'
                               THEN dh.tong_tien ELSE 0 END), 0) >= 1000000  THEN 'Thường'
        WHEN COUNT(dh.id) = 0                                                 THEN 'Chưa mua'
        ELSE                                                                        'Mới'
    END AS phan_loai_khach
FROM khach_hang kh
LEFT JOIN don_hang dh ON kh.id = dh.khach_hang_id
GROUP BY kh.id, kh.ho_ten, kh.thanh_pho
ORDER BY tong_tien_thuc DESC;
```

</details>

---

**Bài 4.3 (Thử thách):** Tìm nhân viên có **lương cao nhất trong mỗi phòng ban**, dùng subquery.

Hiển thị: `phong_ban`, `ho_ten`, `luong`.

<details>
<summary>💡 Gợi ý</summary>

Cách 1: Subquery trong WHERE — `WHERE (phong_ban, luong) IN (SELECT phong_ban, MAX(luong) FROM nhan_vien GROUP BY phong_ban)`

Cách 2: Subquery trong FROM — tạo bảng tạm với `MAX(luong)` theo phòng ban, rồi JOIN lại.

</details>

<details>
<summary>✅ Đáp án — Cách 1 (row constructor)</summary>

```sql
SELECT phong_ban, ho_ten, luong
FROM nhan_vien
WHERE (phong_ban, luong) IN (
    SELECT phong_ban, MAX(luong)
    FROM nhan_vien
    GROUP BY phong_ban
)
ORDER BY phong_ban;
```

</details>

<details>
<summary>✅ Đáp án — Cách 2 (subquery trong FROM + JOIN)</summary>

```sql
SELECT nv.phong_ban, nv.ho_ten, nv.luong
FROM nhan_vien nv
JOIN (
    SELECT phong_ban, MAX(luong) AS luong_max
    FROM nhan_vien
    GROUP BY phong_ban
) AS bang_max ON nv.phong_ban = bang_max.phong_ban
              AND nv.luong = bang_max.luong_max
ORDER BY nv.phong_ban;
```

</details>

---

**Bài 4.4 (Thử thách):** Thống kê **top sản phẩm bán chạy** gồm:
- `ten_sp`, `danh_muc`
- `tong_so_luong_ban` (tổng số lượng, chỉ tính đơn không hủy)
- `tong_doanh_thu`
- `phan_tram_dt` — % đóng góp vào tổng doanh thu (làm tròn 1 chữ số thập phân)
- Sắp xếp theo doanh thu giảm dần

<details>
<summary>💡 Gợi ý</summary>

Dùng subquery để lấy tổng doanh thu chung, rồi chia:
`ROUND(tong_doanh_thu * 100.0 / (SELECT SUM(tong_tien) FROM don_hang WHERE ...), 1)`

</details>

<details>
<summary>✅ Đáp án</summary>

```sql
SELECT
    sp.ten_sp,
    sp.danh_muc,
    SUM(ct.so_luong)                    AS tong_so_luong_ban,
    SUM(ct.so_luong * ct.don_gia)       AS tong_doanh_thu,
    ROUND(
        SUM(ct.so_luong * ct.don_gia) * 100.0 /
        (SELECT SUM(tong_tien) FROM don_hang WHERE trang_thai != 'huy'),
        1
    ) AS phan_tram_dt
FROM san_pham sp
JOIN chi_tiet_don_hang ct ON sp.id = ct.san_pham_id
JOIN don_hang dh ON ct.don_hang_id = dh.id
WHERE dh.trang_thai != 'huy'
GROUP BY sp.id, sp.ten_sp, sp.danh_muc
ORDER BY tong_doanh_thu DESC;
```

</details>

## Tổng Kết

Sau khi hoàn thành bài tập tuần 8, bạn đã thực hành:

| Kỹ năng | Bài luyện |
|---|---|
| Subquery so sánh giá trị | 1.1, 1.2 |
| Subquery `IN` / `NOT IN` | 1.3, 1.4, 1.5 |
| Subquery trong `FROM` | 2.5, 4.3 (cách 2) |
| `CASE WHEN` phân loại | 2.1, 2.2, 4.1 |
| `CASE WHEN` trong `GROUP BY` | 2.3, 3.7 |
| Pivot ngang với `SUM(CASE WHEN...)` | 2.4 |
| Hàm chuỗi (`UPPER`, `LENGTH`, `SUBSTRING`) | 3.1, 3.2, 3.3 |
| Hàm ngày (`EXTRACT`, `AGE`, `TO_CHAR`) | 3.4, 3.5, 3.6, 3.7 |
| `COALESCE` xử lý NULL | 4.1, 4.2 |
| Kết hợp nhiều kỹ năng | 4.2, 4.4 |
