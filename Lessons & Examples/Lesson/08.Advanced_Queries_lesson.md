## 8.1 Subquery — Truy Vấn Lồng Nhau

### Subquery Là Gì?

Subquery (truy vấn con) là **một câu SELECT nằm bên trong câu SELECT khác**.

Hãy nghĩ tương tự Excel: bạn hay lồng hàm vào nhau như `=AVERAGE(IF(B2:B10="IT", C2:C10))`. Subquery làm điều đó trong SQL — tính toán một giá trị hoặc một tập kết quả, rồi dùng nó ở câu truy vấn ngoài.

### Ví Dụ Đầu Tiên: Tìm Nhân Viên Lương Cao Hơn Trung Bình

**Cách nghĩ từng bước (như giải bài toán):**

```
Bước 1: Tính lương trung bình của tất cả nhân viên
        → SELECT AVG(luong) FROM nhan_vien
        → Kết quả: ví dụ 19,500,000

Bước 2: Tìm nhân viên có lương > 19,500,000
        → SELECT ho_ten, luong FROM nhan_vien WHERE luong > 19500000
```

**Viết riêng hai bước thì nhàm. Lồng vào nhau thì gọn:**

```sql
SELECT ho_ten, luong
FROM nhan_vien
WHERE luong > (SELECT AVG(luong) FROM nhan_vien);
```

```
Kết quả minh họa:
┌──────────────────┬──────────┐
│ ho_ten           │ luong    │
├──────────────────┼──────────┤
│ Phạm Minh Châu   │ 25000000 │
│ Nguyễn Văn An    │ 22000000 │
│ Võ Văn Em        │ 22000000 │
│ Nguyễn Thị Ngọc  │ 21000000 │
└──────────────────┴──────────┘
(Những người có lương > mức trung bình ~19.5 triệu)
```

> 💡 **Cách đọc:** "Lấy họ tên và lương từ nhan_vien, **ở đó** lương lớn hơn *(kết quả tính từ)* lương trung bình của toàn bộ nhân_vien."

### Quy Tắc Cú Pháp

```sql
SELECT cot1, cot2
FROM bang_ngoai
WHERE cot > (SELECT ham_tong_hop(cot) FROM bang_trong);
              ↑ subquery nằm trong dấu ngoặc đơn ()
```

**Các điểm cần nhớ:**
- Subquery luôn nằm trong **dấu ngoặc đơn `()`**
- Khi dùng `=`, `>`, `<` → subquery phải trả về **đúng một giá trị** (scalar)
- Khi dùng `IN` → subquery có thể trả về **nhiều giá trị** (danh sách)

## 8.2 Subquery Trong WHERE Với IN / NOT IN

### Dùng IN — "Nằm Trong Danh Sách Này"

Câu hỏi: *Tìm tất cả khách hàng đã từng đặt đơn hàng.*

```sql
-- Cách làm: lấy danh sách khach_hang_id từ bảng don_hang, rồi lọc
SELECT ho_ten, dien_thoai
FROM khach_hang
WHERE id IN (
    SELECT DISTINCT khach_hang_id
    FROM don_hang
);
```

```
Tư duy tương tự Excel:
1. Sheet "don_hang" → lấy cột "khach_hang_id" (loại trùng) → danh sách: {1, 2, 3, 4, 5}
2. Sheet "khach_hang" → lọc những dòng có id nằm trong danh sách đó
→ Giống =COUNTIF(don_hang!B:B, A2) > 0  (rồi lọc những hàng True)
```

### Dùng NOT IN — "KHÔNG Nằm Trong Danh Sách"

Câu hỏi: *Tìm khách hàng CHƯA bao giờ đặt hàng.*

```sql
SELECT ho_ten, dien_thoai
FROM khach_hang
WHERE id NOT IN (
    SELECT DISTINCT khach_hang_id
    FROM don_hang
    WHERE khach_hang_id IS NOT NULL  -- ← QUAN TRỌNG! Giải thích bên dưới
);
```

> ⚠️ **CẢNH BÁO — Bẫy NULL với NOT IN:**
>
> Nếu subquery trả về **bất kỳ một giá trị NULL nào**, `NOT IN` sẽ không trả về kết quả nào cả!
>
> Lý do kỹ thuật: SQL so sánh `id NOT IN (1, 2, NULL)` → SQL không thể khẳng định "id có bằng NULL không" → kết quả là UNKNOWN → hàng bị loại.
>
> **Giải pháp:** Luôn thêm `WHERE cot IS NOT NULL` vào subquery khi dùng `NOT IN`.

### So Sánh: Subquery vs LEFT JOIN IS NULL

Hai cách sau cho kết quả giống nhau — tìm khách chưa đặt hàng:

```sql
-- Cách 1: Subquery NOT IN (dễ đọc hơn)
SELECT ho_ten FROM khach_hang
WHERE id NOT IN (
    SELECT khach_hang_id FROM don_hang WHERE khach_hang_id IS NOT NULL
);

-- Cách 2: LEFT JOIN + IS NULL (hiệu quả hơn khi dữ liệu lớn)
SELECT kh.ho_ten
FROM khach_hang kh
LEFT JOIN don_hang dh ON kh.id = dh.khach_hang_id
WHERE dh.id IS NULL;
```

Cả hai đều đúng. Chọn cách nào dễ đọc hơn với bạn — nhưng ghi nhớ Cách 2 cho tương lai.

## 8.3 Subquery Trong FROM — Bảng Tạm

### Ý Tưởng

Subquery trong `FROM` tạo ra một **bảng tạm thời** (không lưu vào CSDL), rồi bạn truy vấn lên bảng tạm đó.

**Tương đương Excel:** Bạn tính một cột tính toán ở bảng trung gian, rồi dùng bảng đó làm nguồn cho Pivot Table.

### Ví Dụ: Tìm Phòng Ban Có Lương Trung Bình Cao Hơn Mức Trung Bình Chung

```sql
-- Bước 1: Tính lương trung bình theo từng phòng ban → thành "bảng tạm"
-- Bước 2: Lọc những phòng ban có avg_luong > lương trung bình toàn công ty

SELECT phong_ban, avg_luong
FROM (
    -- Subquery này tạo bảng tạm gồm 2 cột: phong_ban + avg_luong
    SELECT
        phong_ban,
        AVG(luong) AS avg_luong
    FROM nhan_vien
    GROUP BY phong_ban
) AS bang_luong_pb             -- ← bảng tạm PHẢI có tên (alias)
WHERE avg_luong > (
    SELECT AVG(luong) FROM nhan_vien
);
```

```
Kết quả minh họa:
┌────────────┬────────────┐
│ phong_ban  │ avg_luong  │
├────────────┼────────────┤
│ IT         │ 23500000   │
│ Kinh doanh │ 21000000   │
└────────────┴────────────┘
(Chỉ những phòng ban có lương TB > mức trung bình toàn công ty)
```

> 💡 **Quy tắc quan trọng:** Bảng tạm trong `FROM` bắt buộc phải có **alias** (tên) — viết `AS ten_bang_tam` sau dấu đóng ngoặc `)`.

### Ví Dụ 2: Thống Kê Khách Hàng + Phân Loại

```sql
-- Bước 1: Tổng hợp dữ liệu mua hàng theo khách (bảng tạm)
-- Bước 2: Phân loại từ bảng tạm đó

SELECT
    ten_khach,
    tong_don,
    tong_tien,
    CASE
        WHEN tong_tien >= 5000000 THEN 'VIP'
        WHEN tong_tien >= 1000000 THEN 'Thường'
        ELSE                           'Mới'
    END AS phan_loai
FROM (
    SELECT
        kh.ho_ten               AS ten_khach,
        COUNT(dh.id)            AS tong_don,
        COALESCE(SUM(dh.tong_tien), 0) AS tong_tien
    FROM khach_hang kh
    LEFT JOIN don_hang dh ON kh.id = dh.khach_hang_id
    GROUP BY kh.id, kh.ho_ten
) AS thong_ke_kh
ORDER BY tong_tien DESC;
```

## 8.4 CASE WHEN — Câu Lệnh IF Của SQL

### So Sánh Với Excel

| Excel | SQL |
|---|---|
| `=IF(B2>20000000, "Cao", "Thấp")` | `CASE WHEN luong > 20000000 THEN 'Cao' ELSE 'Thấp' END` |
| `=IFS(B2>20M, "Cao", B2>15M, "TB", TRUE, "Thấp")` | `CASE WHEN ... THEN ... WHEN ... THEN ... ELSE ... END` |

### Cú Pháp Cơ Bản (Searched CASE)

```sql
CASE
    WHEN điều_kiện_1 THEN kết_quả_1
    WHEN điều_kiện_2 THEN kết_quả_2
    WHEN điều_kiện_3 THEN kết_quả_3
    ELSE kết_quả_mặc_định         -- nếu không điều kiện nào khớp
END
```

> 💡 **Lưu ý:** SQL kiểm tra từ trên xuống dưới và **dừng lại** khi gặp điều kiện đúng đầu tiên — giống `IFS` trong Excel.

### Ví Dụ 1: Phân Loại Nhân Viên Theo Lương

```sql
SELECT
    ho_ten,
    luong,
    CASE
        WHEN luong >= 25000000 THEN 'Cao'
        WHEN luong >= 18000000 THEN 'Trung bình'
        WHEN luong >= 12000000 THEN 'Thấp'
        ELSE                        'Cần xem xét'
    END AS phan_loai_luong
FROM nhan_vien
ORDER BY luong DESC;
```

```
Kết quả minh họa:
┌──────────────────┬──────────┬──────────────────┐
│ ho_ten           │ luong    │ phan_loai_luong  │
├──────────────────┼──────────┼──────────────────┤
│ Phạm Minh Châu   │ 25000000 │ Cao              │
│ Nguyễn Văn An    │ 22000000 │ Trung bình       │
│ Võ Văn Em        │ 22000000 │ Trung bình       │
│ Trần Thị Mai     │ 15000000 │ Trung bình       │
│ Hoàng Thị Dung   │ 13000000 │ Thấp             │
└──────────────────┴──────────┴──────────────────┘
```

### Ví Dụ 2: CASE WHEN Với Điều Kiện Phức Tạp

```sql
-- Đánh giá nhân viên dựa trên cả phòng ban VÀ lương
SELECT
    ho_ten,
    phong_ban,
    luong,
    CASE
        WHEN phong_ban = 'IT'  AND luong >= 20000000 THEN 'IT Senior'
        WHEN phong_ban = 'IT'  AND luong <  20000000 THEN 'IT Junior'
        WHEN phong_ban = 'Kinh doanh' AND luong >= 20000000 THEN 'KD Senior'
        ELSE phong_ban || ' - Thông thường'
    END AS danh_gia
FROM nhan_vien;
```

### Ví Dụ 3: CASE WHEN Trong WHERE

```sql
-- Lọc linh hoạt: nếu phòng IT thì lương > 20tr, ngược lại lương > 15tr
SELECT ho_ten, phong_ban, luong
FROM nhan_vien
WHERE luong > CASE
                  WHEN phong_ban = 'IT' THEN 20000000
                  ELSE 15000000
              END;
```

## 8.5 Simple CASE — So Sánh Bằng Một Giá Trị

Khi bạn chỉ cần so sánh **bằng** (không phải >, <, BETWEEN...), có dạng ngắn gọn hơn:

```sql
-- Dạng Searched CASE (đầy đủ):
CASE
    WHEN phong_ban = 'IT'         THEN 'Công nghệ'
    WHEN phong_ban = 'Kế toán'    THEN 'Tài chính'
    WHEN phong_ban = 'Kinh doanh' THEN 'Bán hàng'
    ELSE 'Khác'
END

-- Dạng Simple CASE (ngắn hơn — chỉ khi so sánh bằng):
CASE phong_ban
    WHEN 'IT'         THEN 'Công nghệ'
    WHEN 'Kế toán'    THEN 'Tài chính'
    WHEN 'Kinh doanh' THEN 'Bán hàng'
    ELSE 'Khác'
END
```

```
Kết quả tương tự Excel:
=SWITCH(F2, "IT","Công nghệ", "Kế toán","Tài chính", "Kinh doanh","Bán hàng", "Khác")
```

> ⚠️ **Hạn chế của Simple CASE:** Chỉ so sánh được bằng (`=`). Khi cần `>`, `<`, `BETWEEN`, `LIKE`, `IS NULL` → phải dùng Searched CASE.

## 8.6 CASE WHEN + GROUP BY — Combo Phân Tích Mạnh

### Dùng CASE WHEN Trong GROUP BY

Câu hỏi: *Thống kê số nhân viên theo nhóm lương — thay vì theo từng phòng ban.*

```sql
SELECT
    CASE
        WHEN luong >= 20000000 THEN 'Nhóm Cao (>= 20tr)'
        WHEN luong >= 15000000 THEN 'Nhóm TB (15-20tr)'
        ELSE                        'Nhóm Thấp (< 15tr)'
    END AS nhom_luong,
    COUNT(*)            AS so_nhan_vien,
    AVG(luong)::NUMERIC(12,0) AS luong_tb_nhom
FROM nhan_vien
GROUP BY
    CASE
        WHEN luong >= 20000000 THEN 'Nhóm Cao (>= 20tr)'
        WHEN luong >= 15000000 THEN 'Nhóm TB (15-20tr)'
        ELSE                        'Nhóm Thấp (< 15tr)'
    END
ORDER BY luong_tb_nhom DESC;
```

> 💡 **Tương đương Excel:** Bạn thêm cột "Nhóm lương" bằng IF(), rồi dùng cột đó làm Rows trong Pivot Table.

### Dùng CASE WHEN Trong SUM — Pivot Ngang

Câu hỏi: *Hiển thị số nhân viên mỗi phòng ban theo từng trạng thái làm việc — trên một hàng.*

```sql
-- Giống "cross-tab" hoặc pivot ngang trong Excel
SELECT
    phong_ban,
    COUNT(*)                                            AS tong_nv,
    SUM(CASE WHEN tinh_trang = 'dang_lam'  THEN 1 ELSE 0 END) AS dang_lam,
    SUM(CASE WHEN tinh_trang = 'nghi_phep' THEN 1 ELSE 0 END) AS nghi_phep,
    SUM(CASE WHEN tinh_trang = 'nghi_viec' THEN 1 ELSE 0 END) AS nghi_viec
FROM nhan_vien
GROUP BY phong_ban
ORDER BY phong_ban;
```

```
Kết quả minh họa:
┌────────────┬────────┬──────────┬───────────┬───────────┐
│ phong_ban  │ tong_nv│ dang_lam │ nghi_phep │ nghi_viec │
├────────────┼────────┼──────────┼───────────┼───────────┤
│ IT         │    3   │    3     │     0     │     0     │
│ Kế toán    │    2   │    1     │     1     │     0     │
│ Kinh doanh │    4   │    3     │     0     │     1     │
│ Nhân sự    │    3   │    2     │     0     │     1     │
└────────────┴────────┴──────────┴───────────┴───────────┘
```

Kỹ thuật `SUM(CASE WHEN ... THEN 1 ELSE 0 END)` là cách tạo **pivot ngang** trong SQL — rất hay dùng trong báo cáo.

## 8.7 Hàm Xử Lý Chuỗi

### Bảng Tra Cứu Nhanh

| Hàm SQL | Hàm Excel | Ví dụ | Kết quả |
|---|---|---|---|
| `UPPER(cot)` | `=UPPER()` | `UPPER('nguyễn an')` | `'NGUYỄN AN'` |
| `LOWER(cot)` | `=LOWER()` | `LOWER('TRẦN MAI')` | `'trần mai'` |
| `LENGTH(cot)` | `=LEN()` | `LENGTH('Hà Nội')` | `6` |
| `TRIM(cot)` | `=TRIM()` | `TRIM('  An  ')` | `'An'` |
| `LTRIM(cot)` | *(không có)* | Xóa khoảng trắng bên trái | — |
| `RTRIM(cot)` | *(không có)* | Xóa khoảng trắng bên phải | — |
| `SUBSTRING(cot, start, len)` | `=MID()` | `SUBSTRING('Hà Nội', 4, 3)` | `'Nội'` |
| `LEFT(cot, n)` | `=LEFT()` | `LEFT('Hà Nội', 2)` | `'Hà'` |
| `RIGHT(cot, n)` | `=RIGHT()` | `RIGHT('Hà Nội', 3)` | `'Nội'` |
| `CONCAT(a, b)` | `=CONCATENATE()` | `CONCAT('Hà', ' Nội')` | `'Hà Nội'` |
| `a \|\| b` | `=A1 & B1` | `'Hà' \|\| ' Nội'` | `'Hà Nội'` |
| `REPLACE(cot, old, new)` | `=SUBSTITUTE()` | `REPLACE('abc', 'b', 'X')` | `'aXc'` |
| `POSITION('x' IN cot)` | `=FIND()` | `POSITION('@' IN 'a@b.com')` | `2` |

### Ví Dụ Thực Tế

```sql
-- Làm sạch và chuẩn hóa dữ liệu email
SELECT
    ho_ten,
    email                           AS email_goc,
    LOWER(TRIM(email))              AS email_chuan,  -- xóa khoảng trắng + viết thường
    LENGTH(email)                   AS do_dai_email
FROM nhan_vien
WHERE email IS NOT NULL;
```

```sql
-- Lấy tên miền email (phần sau @)
SELECT
    ho_ten,
    email,
    SUBSTRING(email, POSITION('@' IN email) + 1, LENGTH(email)) AS ten_mien
FROM nhan_vien
WHERE email IS NOT NULL;
```

```sql
-- Tạo mã nhân viên từ tên + id
-- Format: NV-001 (ho_ten viết tắt + id 3 chữ số)
SELECT
    id,
    ho_ten,
    'NV-' || LPAD(id::TEXT, 3, '0') AS ma_nhan_vien
    -- LPAD: thêm ký tự '0' vào đầu để đủ 3 chữ số
    -- id::TEXT: ép kiểu số thành chuỗi
FROM nhan_vien;
```

```
Kết quả:
┌────┬──────────────────┬──────────────────┐
│ id │ ho_ten           │ ma_nhan_vien     │
├────┼──────────────────┼──────────────────┤
│  1 │ Trần Thị Mai     │ NV-001           │
│  2 │ Nguyễn Văn An    │ NV-002           │
│ 10 │ Lê Văn Minh      │ NV-010           │
└────┴──────────────────┴──────────────────┘
```

## 8.8 Hàm Xử Lý Ngày Tháng

### Bảng Tra Cứu Nhanh

| Hàm SQL | Hàm Excel | Ý nghĩa |
|---|---|---|
| `CURRENT_DATE` | `=TODAY()` | Ngày hôm nay (không có giờ) |
| `NOW()` | `=NOW()` | Ngày giờ hiện tại |
| `EXTRACT(YEAR FROM cot)` | `=YEAR()` | Lấy năm |
| `EXTRACT(MONTH FROM cot)` | `=MONTH()` | Lấy tháng |
| `EXTRACT(DAY FROM cot)` | `=DAY()` | Lấy ngày |
| `EXTRACT(DOW FROM cot)` | `=WEEKDAY()` | Ngày trong tuần (0=CN, 6=Thứ 7) |
| `DATE_PART('year', cot)` | `=YEAR()` | Giống EXTRACT (cú pháp khác) |
| `DATE_TRUNC('month', cot)` | *(không có)* | Cắt về đầu tháng/quý/năm |
| `AGE(date1, date2)` | `=DATEDIF()` | Khoảng cách giữa 2 ngày |
| `date + INTERVAL '30 days'` | `=A1 + 30` | Cộng thêm ngày |
| `date - INTERVAL '1 month'` | `=EDATE(A1, -1)` | Trừ đi 1 tháng |
| `TO_CHAR(date, 'format')` | `=TEXT()` | Định dạng ngày thành chuỗi |

### Ví Dụ Thực Tế

**Tính tuổi nhân viên:**

```sql
SELECT
    ho_ten,
    ngay_sinh,
    EXTRACT(YEAR FROM AGE(CURRENT_DATE, ngay_sinh))::INTEGER AS tuoi
FROM nhan_vien
ORDER BY tuoi;
```

**Tính số năm thâm niên:**

```sql
SELECT
    ho_ten,
    ngay_vao          AS ngay_vao_lam,
    EXTRACT(YEAR FROM AGE(CURRENT_DATE, ngay_vao))::INTEGER  AS nam_tham_nien,
    EXTRACT(MONTH FROM AGE(CURRENT_DATE, ngay_vao))::INTEGER AS thang_le
FROM nhan_vien
ORDER BY ngay_vao;
```

**Thống kê đơn hàng theo tháng — rất hay dùng trong báo cáo:**

```sql
SELECT
    EXTRACT(YEAR FROM ngay_dat)  AS nam,
    EXTRACT(MONTH FROM ngay_dat) AS thang,
    COUNT(*)                     AS so_don,
    SUM(tong_tien)               AS doanh_thu
FROM don_hang
GROUP BY
    EXTRACT(YEAR FROM ngay_dat),
    EXTRACT(MONTH FROM ngay_dat)
ORDER BY nam, thang;
```

**Dùng DATE_TRUNC để nhóm theo tháng (cách gọn hơn):**

```sql
-- DATE_TRUNC('month', ngay_dat) → trả về ngày đầu tháng
-- VD: '2024-03-15' → '2024-03-01'
SELECT
    DATE_TRUNC('month', ngay_dat) AS dau_thang,
    COUNT(*)                      AS so_don,
    SUM(tong_tien)                AS doanh_thu
FROM don_hang
GROUP BY DATE_TRUNC('month', ngay_dat)
ORDER BY dau_thang;
```

**Định dạng ngày thành chuỗi để dễ đọc:**

```sql
SELECT
    ho_ten,
    TO_CHAR(ngay_sinh, 'DD/MM/YYYY')  AS ngay_sinh_vn,
    TO_CHAR(ngay_vao,  'Month YYYY')  AS thang_vao_lam
    -- 'Month' → tên tháng đầy đủ: 'January', 'February'...
FROM nhan_vien;
```

**Lọc dữ liệu 30 ngày gần nhất:**

```sql
SELECT *
FROM don_hang
WHERE ngay_dat >= CURRENT_DATE - INTERVAL '30 days'
ORDER BY ngay_dat DESC;
```

**Phân loại đơn hàng theo quý:**

```sql
SELECT
    ma_don_hang,
    ngay_dat,
    CASE EXTRACT(MONTH FROM ngay_dat)
        WHEN 1  THEN 'Q1' WHEN 2  THEN 'Q1' WHEN 3  THEN 'Q1'
        WHEN 4  THEN 'Q2' WHEN 5  THEN 'Q2' WHEN 6  THEN 'Q2'
        WHEN 7  THEN 'Q3' WHEN 8  THEN 'Q3' WHEN 9  THEN 'Q3'
        ELSE              'Q4'
    END AS quy,
    tong_tien
FROM don_hang
ORDER BY ngay_dat;
```

## 8.9 COALESCE — Xử Lý NULL Một Cách Chuyên Nghiệp

### NULL Là Gì Và Tại Sao Phải Xử Lý?

NULL nghĩa là "không có giá trị" — khác với số 0 hoặc chuỗi rỗng `''`.

```
Trong Excel:
- Ô trống = không có gì
- =A1 + 0 nếu A1 trống → trả về 0
- =IFERROR(VLOOKUP(...), "Không tìm thấy")

Trong SQL:
- NULL + bất kỳ gì = NULL      (NULL "lây" sang kết quả)
- NULL = NULL → FALSE!          (phải dùng IS NULL thay vì = NULL)
- COUNT(cot) bỏ qua NULL       (COUNT(*) mới đếm tất cả)
```

### COALESCE(giá_trị_1, giá_trị_2, ...) — Lấy Giá Trị Đầu Tiên Không NULL

```sql
-- Nếu email NULL → hiển thị 'Chưa có email'
SELECT
    ho_ten,
    COALESCE(email, 'Chưa có email') AS email_hien_thi
FROM nhan_vien;
```

```
Kết quả:
┌──────────────────┬────────────────────────────┐
│ ho_ten           │ email_hien_thi             │
├──────────────────┼────────────────────────────┤
│ Trần Thị Mai     │ mai.tran@email.com         │  ← có email, lấy email
│ Hoàng Văn Đức    │ Chưa có email              │  ← NULL, lấy giá trị dự phòng
└──────────────────┴────────────────────────────┘
```

### Ứng Dụng Thực Tế Của COALESCE

**1. Tránh kết quả NULL trong phép tính:**

```sql
-- LEFT JOIN → khách chưa mua sẽ có SUM = NULL
-- COALESCE đổi NULL thành 0
SELECT
    kh.ho_ten,
    COALESCE(SUM(dh.tong_tien), 0) AS tong_mua
FROM khach_hang kh
LEFT JOIN don_hang dh ON kh.id = dh.khach_hang_id
GROUP BY kh.id, kh.ho_ten;
```

**2. Ưu tiên giá trị: dùng cột A nếu có, không thì dùng cột B:**

```sql
-- Hiện thị tên ưu tiên: nickname trước, nếu NULL thì dùng ho_ten
SELECT
    COALESCE(nickname, ho_ten) AS ten_hien_thi
FROM nhan_vien;
```

**3. Nhãn thân thiện khi dữ liệu chưa đầy đủ:**

```sql
SELECT
    ma_don_hang,
    COALESCE(ghi_chu, '(Không có ghi chú)') AS ghi_chu_hd
FROM don_hang;
```

## 8.10 CTE — Viết Subquery Sạch Hơn (WITH Clause)

### Vấn Đề Với Subquery

Khi subquery phức tạp hoặc lồng nhiều lớp, code trở nên **rất khó đọc**:

```sql
-- ❌ Khó đọc: subquery lồng trong FROM
SELECT phong_ban, avg_luong
FROM (
    SELECT phong_ban, ROUND(AVG(luong), 0) AS avg_luong
    FROM nhan_vien
    WHERE tinh_trang = 'dang_lam'
    GROUP BY phong_ban
) AS luong_pb
WHERE avg_luong > (SELECT AVG(luong) FROM nhan_vien);
```

### CTE — Common Table Expression

CTE cho phép bạn **đặt tên cho subquery** rồi dùng nó phía dưới — đọc **từ trên xuống** thay vì **từ trong ra ngoài**:

```sql
-- ✅ Dễ đọc: CTE (WITH clause)
WITH luong_pb AS (
    SELECT phong_ban, ROUND(AVG(luong), 0) AS avg_luong
    FROM nhan_vien
    WHERE tinh_trang = 'dang_lam'
    GROUP BY phong_ban
)
SELECT phong_ban, avg_luong
FROM luong_pb
WHERE avg_luong > (SELECT AVG(luong) FROM nhan_vien);
```

**So sánh Excel:** Giống khi bạn tạo **sheet trung gian** để tính toán, rồi dùng kết quả đó cho phân tích tiếp. CTE là "sheet trung gian" trong SQL — nhưng tự xóa sau khi query chạy xong.

### CTE Nhiều Bước

Bạn có thể định nghĩa nhiều CTE cách nhau bằng dấu phẩy:

```sql
-- Bước 1: Tính lương trung bình theo phòng ban
-- Bước 2: Tìm phòng ban có lương TB cao hơn mức chung
WITH luong_pb AS (
    SELECT phong_ban, ROUND(AVG(luong), 0) AS avg_luong
    FROM nhan_vien
    GROUP BY phong_ban
),
muc_chung AS (
    SELECT ROUND(AVG(luong), 0) AS avg_cty FROM nhan_vien
)
SELECT
    pb.phong_ban,
    pb.avg_luong,
    mc.avg_cty AS luong_tb_cty,
    pb.avg_luong - mc.avg_cty AS chenh_lech
FROM luong_pb pb, muc_chung mc
WHERE pb.avg_luong > mc.avg_cty
ORDER BY chenh_lech DESC;
```

> 💡 **Khi nào dùng CTE thay vì subquery?**
> - Subquery dùng **nhiều lần** trong cùng query → CTE (viết 1 lần, dùng nhiều lần)
> - Query có **nhiều bước tính toán** → CTE (đọc từ trên xuống)
> - Subquery **đơn giản, dùng 1 lần** → viết trực tiếp cho gọn

## 8.11 Window Functions — Giới Thiệu (Nâng Cao)

### Hạn Chế Của GROUP BY

GROUP BY rất mạnh, nhưng có một giới hạn: **nó "xẹp" nhiều hàng thành 1 hàng**. Đôi khi bạn muốn giữ nguyên từng hàng mà vẫn tính tổng hợp:

```
  Bạn muốn xem:
  ┌──────────────────┬────────────┬──────────┬──────────────────┐
  │ ho_ten           │ phong_ban  │ luong    │ luong_tb_phong   │
  ├──────────────────┼────────────┼──────────┤──────────────────┤
  │ Trần Thị Mai     │ Kế toán    │ 15000000 │       15666667   │
  │ Hoàng Thị Dung   │ Kế toán    │ 13000000 │       15666667   │
  │ Lý Văn Phú       │ Kế toán    │ 19000000 │       15666667   │
  │ Phạm Minh Châu   │ IT         │ 25000000 │       27666667   │
  │ ...              │ ...        │ ...      │ ...              │
  └──────────────────┴────────────┴──────────┴──────────────────┘
```

GROUP BY không làm được điều này — nó chỉ trả về 1 hàng cho Kế toán, 1 hàng cho IT. **Window Functions** giải quyết vấn đề này.

### OVER() + PARTITION BY — Tính Aggregate Trên Từng Hàng

```sql
-- Lương mỗi người + lương trung bình phòng ban trên CÙNG 1 DÒNG
SELECT
    ho_ten,
    phong_ban,
    luong,
    ROUND(AVG(luong) OVER (PARTITION BY phong_ban), 0) AS luong_tb_phong,
    luong - ROUND(AVG(luong) OVER (PARTITION BY phong_ban), 0) AS chenh_lech
FROM nhan_vien
WHERE tinh_trang = 'dang_lam'
ORDER BY phong_ban, luong DESC;
```

**So sánh Excel:** Giống khi bạn có **cột phụ dùng AVERAGEIF** — mỗi hàng có giá trị riêng nhưng đồng thời hiển thị giá trị trung bình của nhóm.

### ROW_NUMBER() và RANK() — Xếp Hạng

```sql
-- Xếp hạng nhân viên theo lương TRONG TỪNG phòng ban
SELECT
    ho_ten,
    phong_ban,
    luong,
    ROW_NUMBER() OVER (PARTITION BY phong_ban ORDER BY luong DESC) AS hang,
    RANK()       OVER (PARTITION BY phong_ban ORDER BY luong DESC) AS thu_hang
FROM nhan_vien
WHERE tinh_trang = 'dang_lam';
```

| Hàm | Cách đánh số | Khi có lương bằng nhau |
|---|---|---|
| `ROW_NUMBER()` | 1, 2, 3, 4, 5 | Luôn đánh số liên tục (ngẫu nhiên ai trước) |
| `RANK()` | 1, 2, 2, 4, 5 | Cùng hạng, rồi bỏ qua (hạng 3 bị mất) |
| `DENSE_RANK()` | 1, 2, 2, 3, 4 | Cùng hạng, không bỏ qua |

### Use Case Phổ Biến: Top N Mỗi Nhóm

```sql
-- Top 2 nhân viên lương cao nhất MỖI phòng ban
WITH xep_hang AS (
    SELECT
        ho_ten, phong_ban, luong,
        ROW_NUMBER() OVER (PARTITION BY phong_ban ORDER BY luong DESC) AS hang
    FROM nhan_vien
    WHERE tinh_trang = 'dang_lam'
)
SELECT ho_ten, phong_ban, luong
FROM xep_hang
WHERE hang <= 2;
```

> 💡 **Nhận ra pattern không?** CTE + Window Functions kết hợp rất mạnh — CTE tạo bảng có xếp hạng, rồi SELECT bên ngoài lọc Top N. Đây là pattern #1 BA hay dùng.

> 📚 **Window Functions là chủ đề rất rộng** — ở đây chỉ giới thiệu nền tảng. Các hàm khác (`SUM() OVER`, `LAG()`, `LEAD()`, `NTILE()`) bạn có thể tìm hiểu thêm khi cần.

## 8.12 Tổng Kết Tuần 8

### Bản Đồ Kiến Thức

```
Tuần 8 — Truy Vấn Nâng Cao
│
├── SUBQUERY
│   ├── Trong WHERE:  WHERE cot > (SELECT ...)        ← lọc theo giá trị tính toán
│   ├── Trong WHERE với IN: WHERE id IN (SELECT ...)  ← lọc theo danh sách
│   └── Trong FROM:   FROM (SELECT ...) AS bang_tam   ← bảng tạm thời
│
├── CTE (WITH clause)
│   ├── Cơ bản: WITH ten AS (SELECT ...) SELECT ... FROM ten
│   └── Nhiều bước: WITH a AS ..., b AS ... SELECT ...
│
├── CASE WHEN
│   ├── Searched CASE: CASE WHEN dk THEN x ELSE y END ← dùng được với mọi điều kiện
│   ├── Simple CASE:   CASE cot WHEN val THEN x END   ← chỉ so sánh bằng
│   └── Trong GROUP BY: phân nhóm theo điều kiện tính toán
│
├── HÀM CHUỖI
│   ├── Làm sạch: TRIM, UPPER, LOWER
│   ├── Cắt/nối: SUBSTRING, LEFT, RIGHT, CONCAT, ||
│   └── Đo lường: LENGTH, POSITION
│
├── HÀM NGÀY THÁNG
│   ├── Lấy thành phần: EXTRACT(YEAR/MONTH/DAY FROM cot)
│   ├── Tính khoảng cách: AGE(date1, date2)
│   ├── Cắt về đầu kỳ: DATE_TRUNC('month'/'quarter'/'year', cot)
│   └── Định dạng: TO_CHAR(date, 'DD/MM/YYYY')
│
└── COALESCE
    └── COALESCE(cot, 'gia_tri_du_phong') ← thay NULL bằng giá trị khác

└── WINDOW FUNCTIONS (giới thiệu)
    ├── AVG/SUM() OVER (PARTITION BY ...) ← aggregate trên từng hàng
    └── ROW_NUMBER(), RANK()              ← xếp hạng trong nhóm
```

### So Sánh Nhanh Excel ↔ SQL — Tuần 8

| Bạn muốn làm gì? | Trong Excel | Trong SQL |
|---|---|---|
| Lọc theo giá trị tính toán | `=FILTER(data, col > AVERAGE(col))` | `WHERE cot > (SELECT AVG(cot) FROM bang)` |
| Kiểm tra có trong danh sách | `=COUNTIF(danh_sach, A2) > 0` | `WHERE id IN (SELECT id FROM ...)` |
| Phân loại điều kiện nhiều mức | `=IFS(B2>20M,"Cao", B2>15M,"TB", TRUE,"Thấp")` | `CASE WHEN ... THEN ... ELSE ... END` |
| Thay thế theo danh sách giá trị | `=SWITCH(A2, "IT","Công nghệ", ...)` | `CASE cot WHEN 'IT' THEN 'Công nghệ' END` |
| Đếm ký tự | `=LEN(A2)` | `LENGTH(cot)` |
| Cắt chuỗi con | `=MID(A2, start, len)` | `SUBSTRING(cot, start, len)` |
| Ngày hôm nay | `=TODAY()` | `CURRENT_DATE` |
| Lấy năm/tháng | `=YEAR(A2)` / `=MONTH(A2)` | `EXTRACT(YEAR FROM cot)` |
| Tính số năm giữa 2 ngày | `=DATEDIF(A2,TODAY(),"Y")` | `EXTRACT(YEAR FROM AGE(CURRENT_DATE, cot))` |
| Xử lý ô trống/lỗi | `=IFERROR(A2, "Mặc định")` | `COALESCE(cot, 'Mặc định')` |
| Tính TB nhóm trên từng dòng | `=AVERAGEIF($C:$C,C2,$D:$D)` | `AVG(cot) OVER (PARTITION BY nhom)` |
| Xếp hạng trong nhóm | Pivot Table + manual | `ROW_NUMBER() OVER (PARTITION BY nhom ORDER BY cot)` |
| Subquery sạch, đọc từ trên xuống | Sheet trung gian | `WITH ten AS (...) SELECT ... FROM ten` |

### Checklist Tuần 8

Sau khi học xong, bạn có thể tự kiểm tra:

- [ ] Tôi có thể viết subquery trong WHERE để so sánh với một giá trị tổng hợp
- [ ] Tôi hiểu sự khác biệt giữa `IN` và `NOT IN`, và biết bẫy NULL với `NOT IN`
- [ ] Tôi có thể tạo bảng tạm trong FROM (và nhớ đặt alias cho nó)
- [ ] Tôi có thể viết `CASE WHEN` với nhiều điều kiện
- [ ] Tôi biết dùng `SUM(CASE WHEN ... THEN 1 ELSE 0 END)` để đếm theo điều kiện
- [ ] Tôi có thể dùng các hàm chuỗi cơ bản: `UPPER`, `LOWER`, `TRIM`, `LENGTH`, `SUBSTRING`
- [ ] Tôi có thể lấy năm/tháng từ ngày với `EXTRACT`, và nhóm dữ liệu theo tháng
- [ ] Tôi biết dùng `COALESCE` để thay thế NULL bằng giá trị mặc định
- [ ] Tôi có thể viết CTE (WITH clause) để thay thế subquery phức tạp
- [ ] Tôi hiểu `AVG() OVER (PARTITION BY ...)` để tính aggregate trên từng hàng
- [ ] Tôi biết dùng `ROW_NUMBER()` để xếp hạng và lọc Top N mỗi nhóm
