Cài Đặt PostgreSQL

Tải · Cài · Kiểm tra PostgreSQL chạy thành công

PostgreSQL Là Gì? (Nhắc Lại Nhanh)

🐘 PostgreSQL là phần mềm quản lý database — giống như Excel là phần mềm quản lý bảng tính. Bạn cần cài nó vào máy để máy tính "hiểu" và lưu trữ dữ liệu theo cách của database.

Bộ cài PostgreSQL gồm có:

⚙️

PostgreSQL Server

"Engine" thật sự xử lý và lưu dữ liệu — chúng ta cần cái này

💻

Command Line Tools

Công cụ dòng lệnh — sẽ dùng ít, không đáng lo

🚫

pgAdmin

Giao diện đồ họa đi kèm — chúng ta dùng DBeaver thay thế (tốt hơn)

📊 Tương tự Excel: PostgreSQL = Excel engine (tính toán ngầm). DBeaver = giao diện Excel (ô, công thức, menu) mà bạn nhìn thấy và dùng hàng ngày.

Bước 1 & 2 — Tải và Chạy Bộ Cài

Chi Tiết Các Màn Hình Cài Đặt

Màn hình installer Cần làm gì
"Setup - PostgreSQL" Nhấn Next
"Installation Directory" Giữ nguyên mặc định → Next

"Password" ⚠️ Đặt mật khẩu — xem slide cảnh báo!

🔑 Mật Khẩu Postgres — Quan Trọng Nhất!

⚠️ CẢNH BÁO — ĐỌC KỸ TRƯỚC KHI ĐẶT MẬT KHẨU

  • Màn hình "Password" yêu cầu đặt mật khẩu cho tài khoản postgres — tài khoản quản trị chính của PostgreSQL
  • Nếu quên mật khẩu: phải gỡ cài đặt hoàn toàn và cài lại — rất mất thời gian
  • Mật khẩu này không phải mật khẩu Windows của bạn — đây là mật khẩu riêng cho PostgreSQL

✅ Nên làm

  • Đặt mật khẩu đơn giản, dễ nhớ
    Ví dụ: postgres123 hoặc Admin@123
  • Ghi ra giấy NGAY BÂY GIỜ — bạn cần nó khi kết nối DBeaver

📌 Bạn sẽ dùng mật khẩu này ở đâu?

1️⃣ Màn hình cài đặt PostgreSQL hôm nay
2️⃣ Điền vào ô Password khi kết nối DBeaver
3️⃣ Mỗi khi reset kết nối về sau

Bước 3 — Kiểm Tra PostgreSQL Đang Chạy

PostgreSQL tự động khởi động như một dịch vụ nền (service) sau khi cài. Kiểm tra:

Cách 1: Task Manager

1

Ctrl + Shift + Esc → mở Task Manager

2

Tab "Services"

3

Tìm postgresql-x64-... → Status: Running

💡 Cách 2: Win + R → gõ services.msc → tìm postgresql-x64-... → phải là Running

Task Manager ┌──────────────────────────────────────────┐ │ Processes Performance App history Services │ ├──────────────────────────────────────────┤ │ Name Status │ │ ... ... │ │ postgresql-x64-16 Running ✅ │ │ ... │ └──────────────────────────────────────────┘ Thấy "Running" → PostgreSQL đang chạy tốt!

⚠️ Nếu không thấy "Running": Click phải vào dịch vụ → "Start". Nếu vẫn không được, thử khởi động lại máy tính.

Xử Lý Lỗi Thường Gặp Khi Kết Nối

Nếu bước "Test Connection" báo lỗi, tra bảng dưới đây:

Thông báo lỗi Nguyên nhân Cách xử lý
Connection refused PostgreSQL chưa khởi động Vào Services → tìm postgresql → Start
password authentication failed Sai mật khẩu Nhập lại đúng mật khẩu bạn đặt khi cài
could not connect to server Sai host hoặc port Kiểm tra: host = localhost, port = 5432
DBeaver hỏi tải driver Cần tải driver PostgreSQL Nhấn "Download" — DBeaver tự tải (cần internet)

📌 Lỗi hay gặp nhất: password authentication failed — thường do gõ sai mật khẩu hoặc nhầm chữ hoa/thường. Hãy kiểm tra lại mật khẩu bạn đã ghi ra giấy.

Tạo Database hoc_sql

📊 Phép so sánh: Tạo database mới giống tạo một file Excel mới (Ctrl+N). Database postgres là file hệ thống — chúng ta không nên làm việc trực tiếp ở đó.

🖱 Cách 1: Click Chuột (UI)

1

Click phải vào "PostgreSQL (localhost)"

2

Chọn "Create New Database"

3

Điền tên: hoc_sql → OK

4

Click phải → Refresh → thấy hoc_sql ✅

💻 Cách 2: Dùng SQL (Làm Quen Dần)

-- Tạo database mới tên hoc_sql
CREATE DATABASE hoc_sql;

Đọc như tiếng Anh: "Tạo — cơ sở dữ liệu — tên là hoc_sql"

⚠️ Quan trọng — Chuyển sang hoc_sql sau khi tạo:
Double-click vào hoc_sql trong Navigator (hoặc click phải → "Set Active"). Tên database đang active sẽ hiện đậm hơn.
Nếu quên: bảng sẽ được tạo trong database sai!

SQL Editor — Câu SQL Đầu Tiên

Khoảnh khắc quan trọng nhất của tuần 2!

Các Câu SQL Kiểm Tra Hệ Thống

Mở SQL Editor: Click phải vào hoc_sql → SQL Editor → New SQL Script

Gõ từng câu, nhấn Ctrl + Enter để chạy:

-- Câu 1: Phiên bản PostgreSQL
SELECT version();
-- Kết quả: PostgreSQL 16.2, compiled...

-- Câu 2: Ngày hôm nay
SELECT current_date;
-- Kết quả: 2026-04-17

-- Câu 3: Ngày và giờ hiện tại
SELECT now();
-- Kết quả: 2026-04-17 14:30:25+07

📊 Tương đương Excel

SQLExcel
current_date=TODAY()
now()=NOW()

💡 Các câu SELECT này không cần bảng — chúng truy vấn thẳng PostgreSQL. Thử ngay để xem kết quả thật!

Tính Toán & Nối Chuỗi Với SQL

-- Câu 4: Tính toán đơn giản
SELECT 1 + 1 AS ket_qua;
-- Kết quả: 2  (cột tên "ket_qua")

-- Câu 5: Tính giờ làm trong năm
SELECT 52 * 5 AS tong_gio_lam_trong_nam;
-- Kết quả: 260

-- Câu 6: Nối chuỗi với ||
SELECT 'Xin chào, ' || 'PostgreSQL!' AS loi_chao;
-- Kết quả: Xin chào, PostgreSQL!

📊 So sánh với Excel

SQLExcel tương đương
1 + 1=1+1 vào ô
AS ket_quaTiêu đề cột trong Excel
'A' || 'B' ="A"&"B" hoặc
=CONCATENATE("A","B")

📌 Ký hiệu nối chuỗi trong PostgreSQL là || (hai thanh đứng). Excel dùng & còn SQL dùng ||.
