Bức Tranh Tổng Thể — GROUP BY = Pivot Table

📊 Pivot Table Excel

Row Labels │ Count │ Sum Lương │ Avg Lương ────────────┼───────┼──────────────┼────────────── IT │ 3 │ 83,000,000 │ 27,666,667 Kế toán │ 3 │ 47,000,000 │ 15,666,667 Kinh doanh │ 4 │ 80,500,000 │ 20,125,000 Nhân sự │ 2 │ 34,000,000 │ 17,000,000

Kéo "Phòng ban" vào Rows, "Lương" vào Values

🐘 GROUP BY SQL

SELECT
    phong_ban,
    COUNT(*) AS so_nv,
    SUM(luong) AS tong_luong,
    ROUND(AVG(luong), 0) AS luong_tb
FROM nhan_vien
GROUP BY phong_ban
ORDER BY phong_ban;

💡 Kết quả y hệt nhau! Bạn đã dùng Pivot Table → bạn đã hiểu GROUP BY về mặt logic rồi.

6.2

COUNT()

Đếm số hàng — tương đương COUNTA() và COUNTIF() trong Excel

COUNT(*) — Đếm Tất Cả Hàng

COUNT(*) đếm toàn bộ hàng trong kết quả, kể cả hàng có NULL ở bất kỳ cột nào.

-- Bao nhiêu nhân viên tất cả?
SELECT COUNT(*) AS tong_nhan_vien
FROM nhan_vien;
tong_nhan_vien ─────────────── 12
-- Đếm nhân viên đang làm việc
SELECT COUNT(*) AS dang_lam
FROM nhan_vien
WHERE tinh_trang = 'dang_lam';

📊 Tương đương Excel

SQLExcel
COUNT(*)=COUNTA(B2:B100)
COUNT(*) WHERE ...=COUNTIF(B2:B100, "đk")

💡 COUNT(*) đếm số hàng, không phải số ô có giá trị. Kể cả hàng mà tất cả cột đều NULL vẫn được đếm.

COUNT(cột) — Bỏ Qua NULL

COUNT(ten_cot) chỉ đếm hàng có giá trị trong cột đó — bỏ qua NULL hoàn toàn.

email COUNT(*) đếm? COUNT(email) đếm? ───────────────────────────────────────────────────────────── mai.tran@cty.com ✅ có ✅ có NULL ✅ có ❌ bỏ qua an.nguyen@cty.com ✅ có ✅ có NULL ✅ có ❌ bỏ qua ───────────────────────────────────────────────────────────── COUNT(*) = 4 COUNT(email) = 2
-- Đếm nhân viên ĐÃ CÓ email
SELECT COUNT(email) AS co_email FROM nhan_vien;

-- Đếm nhân viên CHƯA CÓ email
SELECT COUNT(*) AS chua_co_email FROM nhan_vien WHERE email IS NULL;

3 Dạng COUNT — Phân Biệt Rõ

COUNT(*)

Đếm tất cả hàng
(kể cả hàng có NULL)

≈ COUNTA()

COUNT(cot)

Đếm hàng có giá trị
(bỏ qua NULL)

≈ COUNT()

COUNT(DISTINCT cot)

Đếm giá trị khác nhau
(bỏ trùng lặp)

≈ Remove Duplicates rồi COUNT

-- Có bao nhiêu phòng ban khác nhau?
SELECT COUNT(DISTINCT phong_ban) AS so_phong_ban
FROM nhan_vien;
-- Kết quả: 4  (IT, Kế toán, Kinh doanh, Nhân sự)

-- Trong phòng Kinh doanh có mấy mức lương khác nhau?
SELECT COUNT(DISTINCT luong) AS so_muc_luong
FROM nhan_vien
WHERE phong_ban = 'Kinh doanh';

📌 Nguyên tắc chọn: Muốn đếm hàng → COUNT(*). Muốn đếm hàng có giá trị → COUNT(cot). Muốn đếm các giá trị riêng biệt → COUNT(DISTINCT cot).

6.3

SUM() và AVG()

Tính tổng và trung bình — =SUM() và =AVERAGE() trong Excel

SUM() — Tính Tổng

-- Tổng quỹ lương toàn công ty
SELECT SUM(luong) AS tong_quy_luong
FROM nhan_vien
WHERE tinh_trang = 'dang_lam';
tong_quy_luong ───────────────── 214,500,000 (214.5 triệu đ/tháng)

⚠️ SUM() với NULL

SUM() tự động bỏ qua NULL. Nếu cột lương có một hàng NULL, SUM() vẫn tính đúng tổng cho các hàng còn lại.

💡 Mẹo kiểm tra

-- Kiểm tra tổng có khớp không
SELECT
    SUM(luong) AS tong,
    COUNT(*) AS so_hang,
    COUNT(luong) AS co_gia_tri
FROM nhan_vien;

AVG() — Tính Trung Bình

-- Lương trung bình (làm tròn đến đồng)
SELECT
    ROUND(AVG(luong), 0) AS luong_trung_binh
FROM nhan_vien
WHERE tinh_trang = 'dang_lam';
luong_trung_binh ────────────────── 19,500,000

⚠️ AVG() với NULL — Quan trọng!

AVG() chia tổng cho số hàng CÓ GIÁ TRỊ, không phải tổng số hàng:

3 hàng lương: 10tr, NULL, 20tr AVG(luong) = (10tr + 20tr) / 2 = 15tr ← Đúng Không phải = 30tr / 3 = 10tr ← Sai!

💡 Nên dùng ROUND(AVG(luong), 0) để làm tròn kết quả cho dễ đọc — giống =ROUND(AVERAGE(...), 0) trong Excel.

6.4

MIN() và MAX()

Giá trị nhỏ nhất và lớn nhất — không chỉ dùng cho số!

MIN() / MAX() + Tổng Hợp Tất Cả Hàm

-- Lương cao nhất và thấp nhất
SELECT
    MIN(luong) AS thap_nhat,
    MAX(luong) AS cao_nhat
FROM nhan_vien;

-- Dùng với ngày: ai vào sớm/muộn nhất?
SELECT
    MIN(ngay_vao_lam) AS vao_som_nhat,
    MAX(ngay_vao_lam) AS vao_muon_nhat
FROM nhan_vien;

💡 MIN/MAX không chỉ cho số:
• Ngày tháng: MIN = ngày cũ nhất
• Text: MIN = đầu bảng chữ cái (A...)

Tổng hợp tất cả trong một query:

SELECT
    COUNT(*)                 AS tong_nv,
    COUNT(email)             AS co_email,
    SUM(luong)               AS tong_luong,
    ROUND(AVG(luong), 0)    AS luong_tb,
    MIN(luong)               AS luong_min,
    MAX(luong)               AS luong_max
FROM nhan_vien
WHERE tinh_trang = 'dang_lam';
tong_nv │co_email│ tong_luong│ luong_tb│ luong_min│ luong_max ────────┼────────┼────────────┼──────────┼──────────┼────────── 11 │ 9 │ 214,500,000│19,500,000│13,000,000│30,000,000
6.5

GROUP BY

Nhóm dữ liệu theo cột — Pivot Table trong SQL

Pivot Table Excel ↔ GROUP BY SQL

📊 Cách làm trong Excel (Pivot Table)

  • Kéo "Phòng ban" vào vùng Rows
  • Kéo "Nhân viên" vào Values → Count
  • Kéo "Lương" vào Values → Sum
  • Kéo "Lương" vào Values → Average

Kết quả Pivot Table:

IT │ 3 │ 83,000,000 │ 27,666,667

Kế toán │ 3 │ 47,000,000 │ 15,666,667

Kinh doanh │ 4 │ 80,500,000 │ 20,125,000

Nhân sự │ 2 │ 34,000,000 │ 17,000,000

🐘 Cách làm trong SQL (GROUP BY)

Pivot TableSQL
Kéo vào RowsGROUP BY phong_ban
Values → CountCOUNT(*) trong SELECT
Values → SumSUM(luong) trong SELECT
Values → AverageAVG(luong) trong SELECT
SELECT
    phong_ban,
    COUNT(*) AS so_nhan_vien,
    SUM(luong) AS tong_luong,
    ROUND(AVG(luong),0) AS luong_tb
FROM nhan_vien
GROUP BY phong_ban

Cú Pháp GROUP BY

┌────────────────────────────────────────────────────────────────────┐ │ CÚ PHÁP GROUP BY │ ├────────────────────────────────────────────────────────────────────┤ │ │ │ SELECT cot_nhom, ham_tong_hop(cot_tinh) │ │ FROM ten_bang │ │ WHERE dieu_kien_loc_hang ← Lọc hàng TRƯỚC khi nhóm │ │ GROUP BY cot_nhom; ← Nhóm theo cột này │ │ │ │ QUY TẮC VÀNG: │ │ Mọi cột trong SELECT phải thuộc một trong hai loại: │ │ ├── Cột nhóm: có trong GROUP BY │ │ └── Cột tổng hợp: bên trong COUNT(), SUM(), AVG(), MIN(), MAX() │ └────────────────────────────────────────────────────────────────────┘

📊 Nhớ qua Pivot Table: Cột nhóm = vùng Rows (bạn kéo vào đây). Hàm tổng hợp = vùng Values (phải là số tổng hợp, không phải từng ô đơn lẻ).

⚠️ Quy Tắc Vàng — Lỗi Hay Gặp Nhất

❌ Sai — ho_ten không trong GROUP BY

SELECT phong_ban, ho_ten, COUNT(*)
FROM nhan_vien
GROUP BY phong_ban;
-- ERROR: column "nhan_vien.ho_ten"
-- must appear in the GROUP BY clause
-- or be used in an aggregate function
Vì sao lỗi? Nhóm IT có 3 người: Phạm Minh Châu │ IT │ 25,000,000 Đỗ Thị Phương │ IT │ 30,000,000 Ngô Minh Khánh │ IT │ 28,000,000 ← Máy không biết hiển thị ho_ten nào!

✅ Đúng — chỉ cột nhóm + hàm tổng hợp

-- Chỉ cột nhóm + hàm tổng hợp
SELECT phong_ban, COUNT(*) AS so_nv
FROM nhan_vien
GROUP BY phong_ban;
-- Nếu muốn cả ho_ten: thêm vào GROUP BY
-- (lúc này mỗi người một nhóm)
SELECT phong_ban, ho_ten, COUNT(*)
FROM nhan_vien
GROUP BY phong_ban, ho_ten;

✅ Quy tắc đơn giản: chỉ SELECT những gì bạn đã bỏ vào GROUP BY hoặc bọc trong hàm tổng hợp.

Ví Dụ GROUP BY Thực Tế

-- Đếm nhân viên theo phòng ban
SELECT
    phong_ban,
    COUNT(*) AS so_nhan_vien
FROM nhan_vien
GROUP BY phong_ban
ORDER BY so_nhan_vien DESC;
phong_ban │ so_nhan_vien ────────────┼────────────── Kinh doanh │ 4 IT │ 3 Kế toán │ 3 Nhân sự │ 2
-- Thống kê đầy đủ theo phòng ban
-- (chỉ nhân viên đang làm)
SELECT
    phong_ban,
    COUNT(*) AS so_nv,
    SUM(luong) AS tong_luong,
    ROUND(AVG(luong),0) AS luong_tb,
    MIN(luong) AS luong_min,
    MAX(luong) AS luong_max
FROM nhan_vien
WHERE tinh_trang = 'dang_lam'
GROUP BY phong_ban
ORDER BY luong_tb DESC;

💡 WHERE chạy trước GROUP BY — bộ lọc hàng áp dụng trên dữ liệu thô, trước khi tạo nhóm.

6.6

GROUP BY Nhiều Cột

Nhóm theo nhiều tiêu chí — như nhiều fields trong Rows của Pivot Table

GROUP BY Nhiều Cột

📊 Pivot Table — 2 fields trong Rows

Phòng ban │ Tình trạng │ Count ─────────────┼─────────────┼─────── IT │ dang_lam │ 3 Kế toán │ dang_lam │ 3 Kinh doanh │ dang_lam │ 3 Kinh doanh │ nghi_viec │ 1 Nhân sự │ dang_lam │ 2

🐘 GROUP BY 2 cột

SELECT
    phong_ban,
    tinh_trang,
    COUNT(*) AS so_nhan_vien
FROM nhan_vien
GROUP BY phong_ban, tinh_trang
ORDER BY phong_ban, tinh_trang;

💡 Quy tắc vàng vẫn áp dụng: tất cả cột nhóm (phong_ban, tinh_trang) đều phải có trong GROUP BY.

📌 Thêm ví dụ hữu ích: đếm email theo phòng ban và trạng thái email:

SELECT phong_ban, COUNT(*) AS tong_nv, COUNT(email) AS co_email,
       COUNT(*) - COUNT(email) AS chua_co_email
FROM nhan_vien GROUP BY phong_ban ORDER BY chua_co_email DESC;
6.7

HAVING

Lọc sau khi nhóm — như filter trực tiếp trên kết quả Pivot Table

HAVING — Lọc Nhóm Sau Khi Tổng Hợp

Ví dụ: "Chỉ hiển thị phòng ban có từ 3 nhân viên trở lên"

Bước 1 — GROUP BY tạo nhóm:

phong_ban │ so_nhan_vien ────────────┼────────────── IT │ 3 ← ✅ ≥ 3 Kế toán │ 3 ← ✅ ≥ 3 Kinh doanh │ 4 ← ✅ ≥ 3 Nhân sự │ 2 ← ❌ < 3 bị loại

Bước 2 — HAVING lọc nhóm:

phong_ban │ so_nhan_vien ────────────┼────────────── IT │ 3 Kế toán │ 3 Kinh doanh │ 4
-- Chỉ lấy phòng có ≥ 3 nhân viên
SELECT
    phong_ban,
    COUNT(*) AS so_nhan_vien
FROM nhan_vien
GROUP BY phong_ban
HAVING COUNT(*) >= 3
ORDER BY so_nhan_vien DESC;

📊 Excel tương đương: Tạo Pivot Table xong, rồi dùng "Value Filters" → "Greater Than or Equal To" → 3 để lọc. HAVING làm điều đó tự động ngay trong câu SQL.

Thêm Ví Dụ HAVING

-- Phòng có lương TB trên 18 triệu
SELECT
    phong_ban,
    ROUND(AVG(luong), 0) AS luong_tb
FROM nhan_vien
WHERE tinh_trang = 'dang_lam'
GROUP BY phong_ban
HAVING AVG(luong) > 18000000
ORDER BY luong_tb DESC;
-- Phòng có tổng quỹ lương trên 60tr
SELECT
    phong_ban,
    SUM(luong) AS tong_luong
FROM nhan_vien
WHERE tinh_trang = 'dang_lam'
GROUP BY phong_ban
HAVING SUM(luong) > 60000000
ORDER BY tong_luong DESC;

📌 Nhận xét: HAVING luôn dùng hàm tổng hợp trong điều kiện (AVG(luong), SUM(luong), COUNT(*)...). Đây là dấu hiệu nhận biết để phân biệt với WHERE.

6.8

WHERE vs HAVING

Điểm dễ nhầm nhất — cần nhớ thật rõ!

WHERE vs HAVING — Bảng So Sánh

🔵 WHERE — Lọc Hàng

  • Chạy TRƯỚC GROUP BY
  • Lọc từng hàng đơn lẻ
  • Không dùng hàm tổng hợp
  • Điều kiện trên dữ liệu thô
WHERE phong_ban = 'IT'
WHERE luong > 20000000
WHERE tinh_trang = 'dang_lam'

🟢 HAVING — Lọc Nhóm

  • Chạy SAU GROUP BY
  • Lọc từng nhóm
  • Thường dùng hàm tổng hợp
  • Điều kiện trên kết quả tổng hợp
HAVING COUNT(*) >= 3
HAVING AVG(luong) > 18000000
HAVING SUM(luong) > 60000000

💡 Cách nhớ nhanh: Thấy hàm tổng hợp trong điều kiện (COUNT, SUM, AVG, MIN, MAX) → dùng HAVING. Điều kiện trên từng hàng thông thường → dùng WHERE.

6.9

Kết Hợp Đầy Đủ

WHERE + GROUP BY + HAVING + ORDER BY — câu SQL hoàn chỉnh

Ví Dụ Thực Tế — Từ Yêu Cầu Đến SQL

"Với nhân viên đang làm việc, cho tôi các phòng có từ 2 người trở lên VÀ lương TB trên 17 triệu. Sắp theo lương TB cao nhất."

SELECT
    phong_ban,
    COUNT(*) AS so_nhan_vien,
    ROUND(AVG(luong),0) AS luong_tb,
    MIN(luong) AS luong_min,
    MAX(luong) AS luong_max
FROM nhan_vien
WHERE tinh_trang = 'dang_lam'  ← ① Lọc hàng
GROUP BY phong_ban               ← ② Tạo nhóm
HAVING COUNT(*) >= 2            ← ③ Lọc nhóm (1)
   AND AVG(luong) > 17000000   ← ③ Lọc nhóm (2)
ORDER BY luong_tb DESC;          ← ④ Sắp xếp

Alias — Ai Dùng Được, Ai Không?

⚠️ Lỗi phổ biến: Dùng alias (đặt trong SELECT) ở HAVING — bị lỗi vì HAVING chạy trước SELECT:

❌ Sai — alias trong HAVING

SELECT phong_ban,
    ROUND(AVG(luong),0) AS luong_tb
FROM nhan_vien
GROUP BY phong_ban
HAVING luong_tb > 18000000;
-- ERROR: column "luong_tb" does not exist

✅ Đúng — lặp lại hàm trong HAVING

SELECT phong_ban,
    ROUND(AVG(luong),0) AS luong_tb
FROM nhan_vien
GROUP BY phong_ban
HAVING AVG(luong) > 18000000;
-- ✅ Lặp lại AVG(luong), không dùng alias
