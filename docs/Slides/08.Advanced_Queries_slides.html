8.1

Subquery — Truy Vấn Lồng Nhau

Một câu SELECT nằm bên trong câu SELECT khác

💡 Ví Dụ: Nhân Viên Lương Cao Hơn Trung Bình

Câu truy vấn ngoài (outer query):

SELECT ho_ten, luong FROM nhan_vien WHERE luong >

↳ Subquery (truy vấn con) — chạy TRƯỚC:
SELECT AVG(luong) FROM nhan_vien → Kết quả: 19,500,000 
-- Viết gọn: lồng vào nhau
SELECT ho_ten, luong
FROM nhan_vien
WHERE luong > (SELECT AVG(luong) FROM nhan_vien);

📊 Excel: Giống hàm lồng =AVERAGE(IF(...)) — tính giá trị bên trong trước, dùng kết quả cho công thức ngoài.

📝 Quy Tắc Cú Pháp Subquery

SELECT cot1, cot2
FROM bang_ngoai
WHERE cot > (SELECT ham_tong_hop(cot) FROM bang_trong);
              ↑ subquery nằm trong dấu ngoặc đơn ()
1

Luôn nằm trong dấu ngoặc ()

2

Dùng =, >, < → subquery phải trả về đúng 1 giá trị (scalar)

3

Dùng IN → subquery có thể trả về nhiều giá trị (danh sách)

8.2

Subquery + IN / NOT IN

Lọc theo danh sách kết quả từ subquery

📋 IN & NOT IN — Lọc Theo Danh Sách

✅ IN — "nằm trong danh sách"

-- Khách đã đặt hàng
SELECT ho_ten
FROM khach_hang
WHERE id IN (
    SELECT DISTINCT khach_hang_id
    FROM don_hang
);

🚫 NOT IN — "không nằm trong"

-- Khách CHƯA đặt hàng
SELECT ho_ten
FROM khach_hang
WHERE id NOT IN (
    SELECT khach_hang_id
    FROM don_hang
    WHERE khach_hang_id IS NOT NULL
);

⚠️ Bẫy NULL với NOT IN: Nếu subquery trả về bất kỳ giá trị NULL nào → NOT IN sẽ không trả kết quả nào cả!

Giải pháp: Luôn thêm WHERE cot IS NOT NULL vào subquery khi dùng NOT IN.

8.3

Subquery Trong FROM

Tạo "bảng tạm" rồi truy vấn lên đó

📦 Ví Dụ: Phòng Ban Lương Cao Hơn Trung Bình

SELECT phong_ban, avg_luong
FROM (
    -- Subquery tạo "bảng tạm" gồm 2 cột
    SELECT phong_ban, AVG(luong) AS avg_luong
    FROM nhan_vien
    GROUP BY phong_ban
) AS bang_luong_pb       ← bảng tạm PHẢI có alias
WHERE avg_luong > (
    SELECT AVG(luong) FROM nhan_vien
);

📊 Excel: Giống tính cột trung gian rồi dùng làm nguồn Pivot Table — bước 1 tính, bước 2 phân tích.

💡 Quy tắc: Bảng tạm trong FROM bắt buộc có alias — viết AS ten_bang sau ).

8.4

CASE WHEN

Câu lệnh IF của SQL — phân loại dữ liệu theo điều kiện

📝 Cú Pháp CASE WHEN

📊 Excel

=IFS(
  B2>20M, "Cao",
  B2>15M, "TB",
  TRUE, "Thấp"
)

🐘 SQL

CASE
  WHEN luong > 20000000 THEN 'Cao'
  WHEN luong > 15000000 THEN 'TB'
  ELSE 'Thấp'
END
WHEN luong > 20M→'Cao'
WHEN luong > 15M→'Trung bình'
ELSE (tất cả còn lại)→'Thấp'

💡 SQL kiểm tra từ trên xuống dưới và dừng khi gặp điều kiện đúng đầu tiên — giống IFS trong Excel.

💻 Ví Dụ: Phân Loại Nhân Viên Theo Lương

SELECT
    ho_ten, luong,
    CASE
        WHEN luong >= 25000000 THEN 'Cao'
        WHEN luong >= 18000000 THEN 'Trung bình'
        WHEN luong >= 12000000 THEN 'Thấp'
        ELSE                        'Cần xem xét'
    END AS phan_loai_luong
FROM nhan_vien
ORDER BY luong DESC;
Kết quả: ┌──────────────────┬──────────┬──────────────────┐ │ ho_ten │ luong │ phan_loai_luong │ ├──────────────────┼──────────┼──────────────────┤ │ Phạm Minh Châu │ 25000000 │ Cao │ │ Nguyễn Văn An │ 22000000 │ Trung bình │ │ Trần Thị Mai │ 15000000 │ Thấp │ │ Hoàng Thị Dung │ 13000000 │ Thấp │ └──────────────────┴──────────┴──────────────────┘

🔄 Simple CASE — So Sánh Bằng Một Giá Trị

Khi chỉ cần so sánh bằng (=), có dạng ngắn gọn hơn:

Searched CASE (đầy đủ)

CASE
  WHEN phong_ban = 'IT'     THEN 'Công nghệ'
  WHEN phong_ban = 'Kế toán' THEN 'Tài chính'
  ELSE 'Khác'
END

Simple CASE (ngắn hơn)

CASE phong_ban
  WHEN 'IT'     THEN 'Công nghệ'
  WHEN 'Kế toán' THEN 'Tài chính'
  ELSE 'Khác'
END

📊 Excel: Simple CASE giống =SWITCH(F2, "IT","Công nghệ", "Kế toán","Tài chính", "Khác")

⚠️ Hạn chế: Simple CASE chỉ so sánh bằng (=). Cần >, <, BETWEEN, LIKE → phải dùng Searched CASE.

8.6

CASE WHEN + GROUP BY

Combo phân tích mạnh — Pivot Table phiên bản SQL

📊 SUM(CASE WHEN) — Pivot Ngang Trong SQL

-- Đếm nhân viên mỗi phòng ban theo trạng thái
SELECT
    phong_ban,
    COUNT(*)                                     AS tong,
    SUM(CASE WHEN tinh_trang = 'dang_lam'  THEN 1 ELSE 0 END) AS dang_lam,
    SUM(CASE WHEN tinh_trang = 'nghi_phep' THEN 1 ELSE 0 END) AS nghi_phep,
    SUM(CASE WHEN tinh_trang = 'nghi_viec' THEN 1 ELSE 0 END) AS nghi_viec
FROM nhan_vien
GROUP BY phong_ban;
Kết quả (pivot ngang): ┌────────────┬──────┬──────────┬───────────┬───────────┐ │ phong_ban │ tong │ dang_lam │ nghi_phep │ nghi_viec │ ├────────────┼──────┼──────────┼───────────┼───────────┤ │ IT │ 3 │ 3 │ 0 │ 0 │ │ Kế toán │ 2 │ 1 │ 1 │ 0 │ │ Kinh doanh │ 4 │ 3 │ 0 │ 1 │ └────────────┴──────┴──────────┴───────────┴───────────┘

💡 Kỹ thuật SUM(CASE WHEN ... THEN 1 ELSE 0 END) — cách tạo pivot ngang trong SQL. Rất hay dùng trong báo cáo!

Hàm Xử Lý Chuỗi

UPPER, LOWER, TRIM, SUBSTRING, CONCAT — làm sạch dữ liệu text

🔤 Hàm Chuỗi Hay Dùng

UPPER(cot)
Excel: =UPPER()
Viết hoa toàn bộ
LOWER(cot)
Excel: =LOWER()
Viết thường toàn bộ
TRIM(cot)
Excel: =TRIM()
Xóa khoảng trắng đầu/cuối
LENGTH(cot)
Excel: =LEN()
Đếm số ký tự
SUBSTRING(cot, start, len)
Excel: =MID()
Cắt chuỗi con
LEFT(cot, n) / RIGHT(cot, n)
Excel: =LEFT() =RIGHT()
Lấy n ký tự đầu/cuối
CONCAT(a, b) hoặc a || b
Excel: =A1 & B1
Nối chuỗi
REPLACE(cot, old, new)
Excel: =SUBSTITUTE()
Thay thế chuỗi con
-- Tạo mã nhân viên: NV-001, NV-002...
SELECT id, ho_ten,
    'NV-' || LPAD(id::TEXT, 3, '0') AS ma_nv
FROM nhan_vien;
8.8

Hàm Xử Lý Ngày Tháng

EXTRACT, AGE, DATE_TRUNC, TO_CHAR — công cụ báo cáo theo thời gian

📅 Hàm Ngày Tháng Hay Dùng

CURRENT_DATE
Excel: =TODAY()
Ngày hôm nay
NOW()
Excel: =NOW()
Ngày + giờ hiện tại
EXTRACT(YEAR FROM cot)
Excel: =YEAR()
Lấy năm/tháng/ngày
AGE(date1, date2)
Excel: =DATEDIF()
Khoảng cách 2 ngày
DATE_TRUNC('month', cot)
(không có)
Cắt về đầu tháng/quý/năm
TO_CHAR(date, 'format')
Excel: =TEXT()
Định dạng ngày → chuỗi
-- Tính tuổi nhân viên
SELECT ho_ten,
    EXTRACT(YEAR FROM AGE(CURRENT_DATE, ngay_sinh))::INTEGER AS tuoi
FROM nhan_vien ORDER BY tuoi;

📈 Thống Kê Doanh Thu Theo Tháng

-- Cách 1: EXTRACT — tách năm, tháng riêng
SELECT
    EXTRACT(YEAR FROM ngay_dat)  AS nam,
    EXTRACT(MONTH FROM ngay_dat) AS thang,
    COUNT(*)                     AS so_don,
    SUM(tong_tien)               AS doanh_thu
FROM don_hang
GROUP BY nam, thang ORDER BY nam, thang;
-- Cách 2: DATE_TRUNC — gọn hơn
SELECT
    DATE_TRUNC('month', ngay_dat) AS dau_thang,
    COUNT(*)                      AS so_don,
    SUM(tong_tien)                AS doanh_thu
FROM don_hang
GROUP BY DATE_TRUNC('month', ngay_dat)
ORDER BY dau_thang;

💡 DATE_TRUNC('month', '2024-03-15') → '2024-03-01' — cắt về ngày đầu tháng, rất tiện cho GROUP BY theo kỳ.

8.9

COALESCE — Xử Lý NULL

Thay NULL bằng giá trị dự phòng — IFERROR phiên bản SQL

🛡️ COALESCE — Lấy Giá Trị Đầu Tiên Không NULL

-- Nếu email NULL → hiển thị 'Chưa có email'
SELECT ho_ten,
    COALESCE(email, 'Chưa có email') AS email_hien_thi
FROM nhan_vien;

Tránh NULL trong phép tính

SELECT kh.ho_ten,
    COALESCE(SUM(dh.tong_tien), 0) AS tong
FROM khach_hang kh
LEFT JOIN don_hang dh ON ...
GROUP BY kh.id, kh.ho_ten;

Ưu tiên giá trị

-- nickname trước, nếu NULL → ho_ten
SELECT
    COALESCE(nickname, ho_ten)
    AS ten_hien_thi
FROM nhan_vien;

📊 Excel: COALESCE giống =IFERROR(A1, "Mặc định") hoặc =IF(ISBLANK(A1), "Rỗng", A1)
