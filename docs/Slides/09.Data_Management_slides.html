9.1

UPDATE — Sửa Dữ Liệu

Thay đổi giá trị trong các hàng hiện có — như sửa ô trong Excel

📝 Cú Pháp UPDATE

UPDATE ten_bang
SET    cot1 = gia_tri_moi,
       cot2 = gia_tri_moi
WHERE  dieu_kien;   ← QUAN TRỌNG — không có WHERE → SỬA TẤT CẢ!

⚠️ UPDATE KHÔNG CÓ WHERE = SỬA TOÀN BỘ BẢNG!

Không thể Ctrl+Z trong database! Dữ liệu mất là mất vĩnh viễn.

-- Ví dụ: Tăng lương 10% cho phòng IT
UPDATE nhan_vien
SET    luong = luong * 1.10
WHERE  phong_ban = 'IT';

📊 Excel: UPDATE giống chọn một vùng ô → sửa → Enter. Nhưng SQL sửa hàng loạt theo điều kiện WHERE.

🔧 UPDATE Nâng Cao — CASE WHEN & Subquery

-- UPDATE với CASE WHEN: tăng lương theo mức khác nhau
UPDATE nhan_vien
SET luong = CASE
    WHEN luong < 15000000 THEN luong * 1.15    -- +15%
    WHEN luong < 25000000 THEN luong * 1.10    -- +10%
    ELSE                        luong * 1.05    -- +5%
END;
-- UPDATE từ bảng khác (subquery)
UPDATE san_pham
SET trang_thai = 'ban_chay'
WHERE id IN (
    SELECT san_pham_id
    FROM chi_tiet_don_hang
    GROUP BY san_pham_id
    HAVING SUM(so_luong) > 50
);
9.2

DELETE — Xóa Dữ Liệu

Xóa hàng theo điều kiện — CẨN THẬN NHẤT trong SQL

📝 Cú Pháp DELETE

DELETE FROM ten_bang
WHERE dieu_kien;  ← KHÔNG CÓ WHERE → XÓA TOÀN BỘ!

⚠️ DELETE KHÔNG CÓ WHERE = XÓA TOÀN BỘ DỮ LIỆU!

Khác với Excel — KHÔNG có thùng rác hay Ctrl+Z!

-- Ví dụ: Xóa đơn hàng đã hủy
DELETE FROM don_hang
WHERE trang_thai = 'da_huy';

🔗 Thứ tự xóa quan trọng: Khi bảng có Foreign Key, phải xóa bảng con trước, bảng cha sau:

1. DELETE FROM chi_tiet_don_hang WHERE don_hang_id = 5;
2. DELETE FROM don_hang WHERE id = 5; ← sau khi xóa con

-- Bước 1: Xem trước — những hàng nào bị ảnh hưởng?
SELECT * FROM nhan_vien
WHERE phong_ban = 'IT' AND luong < 15000000;

9.5

Transaction — Undo Cho Database

Gom nhiều thao tác thành MỘT — hoặc hoàn tất, hoặc hủy hết

🏦 Ví Dụ: Chuyển Tiền Giữa Tài Khoản

Chuyển 1 triệu từ tài khoản A sang B. Có 2 thao tác:

❓ Không có Transaction

1. Trừ tiền A ← thành công
2. Cộng tiền B ← LỖI MẠNG!

→ Mất 1 triệu! A bị trừ nhưng B không nhận.

✅ Có Transaction

BEGIN → Trừ A → Cộng B
Nếu lỗi → ROLLBACK → về ban đầu

→ An toàn! Hoặc cả hai thành công, hoặc không gì thay đổi.

📊 Excel: Transaction giống Ctrl+Z nhưng cho nhiều thao tác cùng lúc — undo hết hoặc giữ hết.

📝 BEGIN / COMMIT / ROLLBACK

BEGIN;Bắt đầu transaction — từ đây mọi thay đổi là "tạm"
UPDATE tai_khoan SET so_du = so_du - 1000000 WHERE id = 1;
UPDATE tai_khoan SET so_du = so_du + 1000000 WHERE id = 2;
COMMIT;✅ Mọi thay đổi được LƯU vĩnh viễn

— hoặc nếu có lỗi —

BEGIN;
UPDATE ... (trừ tiền A)
UPDATE ... (cộng tiền B) — LỖI!
ROLLBACK;❌ HỦY TẤT CẢ — quay về trạng thái trước BEGIN

📌 SAVEPOINT — Điểm Lưu Trong Transaction

Đặt "checkpoint" bên trong transaction — rollback một phần thay vì toàn bộ:

BEGIN;

UPDATE nhan_vien SET luong = luong * 1.1 WHERE phong_ban = 'IT';
SAVEPOINT sau_tang_luong;    ← checkpoint!

DELETE FROM nhan_vien WHERE tinh_trang = 'nghi_viec';
-- Hmm, xóa nhầm! Quay lại checkpoint:

ROLLBACK TO sau_tang_luong;  ← chỉ hủy DELETE, giữ UPDATE

COMMIT;  ← lưu: tăng lương OK, xóa bị hủy

💡 Hãy dùng SAVEPOINT khi transaction có nhiều bước — nếu sai một bước, không cần hủy hết từ đầu.

9.7

VIEW — Truy Vấn Có Tên

Lưu câu SELECT phức tạp thành "bảng ảo" dùng lại nhiều lần

📝 Tạo & Sử Dụng VIEW

-- Tạo VIEW — lưu câu query phức tạp
CREATE VIEW v_bao_cao_khach AS
SELECT
    kh.ho_ten, kh.dien_thoai,
    COUNT(dh.id)          AS so_don_hang,
    COALESCE(SUM(dh.tong_tien), 0) AS tong_chi_tieu
FROM khach_hang kh
LEFT JOIN don_hang dh ON kh.id = dh.khach_hang_id
GROUP BY kh.id, kh.ho_ten, kh.dien_thoai;

-- Dùng VIEW như một bảng bình thường!
SELECT * FROM v_bao_cao_khach
WHERE tong_chi_tieu > 10000000
ORDER BY tong_chi_tieu DESC;

📊 Excel: VIEW giống Named Range hoặc Pivot Table đã lưu — đặt tên cho một phép tính, dùng lại bất cứ lúc nào.

🤔 Khi Nào Dùng VIEW?

✅ Nên dùng VIEW

  • Báo cáo chạy lặp lại nhiều lần
  • Query dài 10+ dòng, dùng ở nhiều nơi
  • Ẩn logic phức tạp cho người dùng khác
  • Giới hạn cột nhạy cảm (lương, CMND)

⏭️ Không cần VIEW

  • Query chỉ dùng 1 lần
  • Query đơn giản 2-3 dòng
  • Cần kết quả tức thì, không dùng lại
-- Quản lý VIEW
DROP VIEW IF EXISTS v_bao_cao_khach;       -- Xóa VIEW
CREATE OR REPLACE VIEW v_ten AS ...;      -- Sửa VIEW

🔧 ALTER TABLE — Sửa Cấu Trúc Bảng

Khi cần thay đổi "thiết kế" bảng — thêm/xóa/sửa cột:

-- Thêm cột mới
ALTER TABLE nhan_vien
ADD COLUMN email VARCHAR(100);

-- Đổi kiểu dữ liệu
ALTER TABLE nhan_vien
ALTER COLUMN dien_thoai TYPE VARCHAR(15);

-- Đặt giá trị mặc định
ALTER TABLE nhan_vien
ALTER COLUMN tinh_trang SET DEFAULT 'dang_lam';

-- Xóa cột (CẨN THẬN — mất dữ liệu!)
ALTER TABLE nhan_vien
DROP COLUMN ghi_chu;

📊 Excel: ALTER TABLE giống Insert Column / Delete Column + Format Cells — thay đổi cấu trúc bảng.

Import CSV

Đưa dữ liệu từ Excel/CSV vào PostgreSQL

📥 Nhập Dữ Liệu Từ CSV

🖱️ Cách 1: DBeaver (GUI)

1

Click phải bảng → Import Data

2

Chọn file CSV

3

Map cột → Preview → Import

⌨️ Cách 2: Lệnh COPY (SQL)

-- Copy từ file CSV
COPY nhan_vien(ho_ten, luong, phong_ban)
FROM '/path/to/file.csv'
WITH (
    FORMAT csv,
    HEADER true,
    DELIMITER ',',
    ENCODING 'UTF8'
);

💡 Mẹo: Lưu file Excel thành CSV (UTF-8) trước khi import. Kiểm tra encoding nếu tiếng Việt bị lỗi font.
