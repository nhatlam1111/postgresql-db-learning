3.1

Kiểu Dữ Liệu (Data Types)

Tại sao phải khai báo kiểu dữ liệu?

8 Kiểu Dữ Liệu Thiết Yếu — Dùng Hằng Ngày

Học kỹ 8 kiểu này trước — chúng đủ để xây dựng phần lớn các bảng bạn cần.

Nhóm Kiểu dữ liệu Dùng khi nào Excel tương đương
Số nguyên INTEGER Id, số lượng — mặc định Số nguyên
SERIAL Cột id tự tăng Fill Series tự động
Số thập phân NUMERIC(p,s) Tiền tệ, kế toán Number (decimal)
Chuỗi VARCHAR(n) Tên, email, địa chỉ Text giới hạn
TEXT Mô tả dài, ghi chú Text tự do
Ngày / Giờ DATE Ngày sinh, ngày hết hạn Date format
TIMESTAMP Ghi log, thời gian tạo Date + Time
Đúng / Sai BOOLEAN Trạng thái, cờ bật/tắt TRUE / FALSE

🔢 INTEGER (INT) — Số Nguyên Thông Dụng Nhất

CREATE TABLE vi_du (
    id          INTEGER,
    so_luong    INTEGER,
    nam_sinh    INTEGER
);
Thuộc tínhGiá trị

💡 Quy tắc ngón tay cái

Khi không chắc nên dùng kiểu số nào → chọn INTEGER

Ví dụ thực tế:

  • Id bảng
  • Số lượng hàng tồn kho
  • Năm sinh
  • Điểm số (1-100)

⚠️ Số điện thoại bắt đầu bằng 0 → nên dùng VARCHAR thay vì INTEGER!

🔄 SERIAL — Số Tự Tăng (Auto Increment)

-- Khi bạn viết:
id SERIAL PRIMARY KEY

-- PostgreSQL thực ra tạo:
CREATE SEQUENCE nhan_vien_id_seq;
id INTEGER NOT NULL
   DEFAULT nextval('nhan_vien_id_seq')
   PRIMARY KEY

⚠️ SERIAL không lấp đầy số bị thiếu!

Xóa id = 3 → id tiếp theo vẫn là 4, không quay lại 3.

id: 1, 2, 4, 5, 7 ... ← Hoàn toàn ổn!

📊 So sánh Excel

Excel (thủ công):
┌────┬──────────┐
│ 1  │ Trần Mai │   ← Bạn tự gõ STT
│ 2  │ Nguyễn An│
│ 3  │ Lê Bình  │

PostgreSQL SERIAL (tự động):
INSERT → id = 1  ← Tự động!
INSERT → id = 2  ← Tự động!
INSERT → id = 3  ← Tự động!

💰 NUMERIC(p, s) — Chính Xác Tuyệt Đối

Dùng cho tiền tệ, kế toán — bất kỳ số nào cần chính xác 100%.

NUMERIC(10, 2)
         ↑   ↑
         p   s
-- p = tổng số chữ số
-- s = chữ số sau dấu thập phân

-- Ví dụ hợp lệ:
12345678.99  ← 8+2=10 chữ số ✅

-- Ví dụ bị lỗi:
123456789.99 ← 9+2=11 > p=10 ❌

⚠️ KHÔNG dùng REAL hay DOUBLE cho tiền tệ — chúng có lỗi làm tròn!

Gợi ý cho các trường hợp thường gặp:

Trường hợpKiểu gợi ý
Lương (VNĐ)NUMERIC(12, 2)
Giá sản phẩmNUMERIC(10, 2)
Tỷ lệ %NUMERIC(5, 2)
Tọa độ GPSNUMERIC(10, 7)
-- Ví dụ khai báo:
luong       NUMERIC(12, 2),
ty_le_chiet NUMERIC(5, 4)

📝 VARCHAR(n) & TEXT — Chuỗi Ký Tự

VARCHAR(n) — Có giới hạn

-- Giới hạn tối đa n ký tự
ho_ten   VARCHAR(100),
email    VARCHAR(150),
dia_chi  VARCHAR(255)

✅ Database tự kiểm tra và từ chối nếu vượt quá n ký tự

✅ n là ràng buộc nghiệp vụ: "email tối đa 150 ký tự"

-- Quá dài → Lỗi!
-- ho_ten VARCHAR(10)
'Nguyễn Văn An Toàn Bình' ← 22 ký tự > 10 ❌

TEXT — Không giới hạn

-- Lưu bao nhiêu cũng được (~1 GB)
mo_ta     TEXT,
noi_dung  TEXT,
ghi_chu   TEXT

✅ Không biết trước độ dài tối đa

✅ Nội dung có thể rất dài (mô tả, bình luận)

💡 Hiệu năng: TEXT và VARCHAR không khác nhau về tốc độ trong PostgreSQL.

📊 Excel: VARCHAR(n) = Data Validation "text length ≤ n"  ·  TEXT = Ô không giới hạn (General)

📅 DATE & TIMESTAMP — Ngày Tháng & Thời Gian

DATE — Chỉ ngày

ngay_sinh    DATE,
ngay_het_han DATE

Format: 'YYYY-MM-DD' (ISO 8601)

'2024-01-15'   ← 15/1/2024 ✅
'2024-02-29'   ← Năm nhuận ✅
'2023-02-29'   ← LỖI! ❌
'2024-13-01'   ← Tháng 13 ❌

💡 Dùng 'YYYY-MM-DD' để không bao giờ nhầm DD/MM với MM/DD!

TIMESTAMP — Ngày + Giờ

ngay_vao TIMESTAMP DEFAULT NOW()

Format: 'YYYY-MM-DD HH:MM:SS'

'2024-01-15 14:30:00'     ✅
'2024-01-15 14:30:59.123' ✅

🧮 Phép tính với DATE

-- Tính số ngày giữa 2 ngày
'2024-12-31'::DATE - '2024-01-01'::DATE
-- → 365

-- Ngày hôm nay
SELECT CURRENT_DATE;

✅ BOOLEAN — Đúng / Sai / Chưa Biết

dang_lam       BOOLEAN DEFAULT TRUE,
da_thanh_toan  BOOLEAN DEFAULT FALSE,
la_vip         BOOLEAN
Giá trịCác cách viết
TRUETRUE, 'yes', '1', 'on'
FALSEFALSE, 'no', '0', 'off'
NULLNULL (không biết)
-- Lọc nhân viên đang làm
WHERE dang_lam = TRUE
-- hoặc ngắn gọn:
WHERE dang_lam

-- Lọc nhân viên đã nghỉ
WHERE NOT dang_lam

⚠️ NULL ≠ FALSE

TRUE = Đúng, có, bật

FALSE = Sai, không, tắt

NULL = Không biết (chưa xác định)

Cột da_gui_email:

• TRUE → Đã gửi

• FALSE → Chưa gửi (biết chắc)

• NULL → Chưa biết (không xác định)

📊 Excel: Ô chứa TRUE/FALSE dùng trong hàm IF().

📋 Bảng Tra Cứu Nhanh — Chọn Kiểu Dữ Liệu

Câu hỏi cần trả lời → Kiểu dữ liệu nên dùng
Cột id tự tăng?SERIAL
Số nguyên thông thường?INTEGER
Tiền tệ, giá cả (cần chính xác)?NUMERIC(p, s)

3.2

Tạo Bảng — CREATE TABLE

Cú pháp cơ bản

CREATE TABLE ten_bang (
    ten_cot_1  kieu_du_lieu  [rang_buoc],
    ten_cot_2  kieu_du_lieu  [rang_buoc],
    ...
);

📏 Quy tắc đặt tên

  • Chữ thường, snake_case: nhan_vien, ho_ten
  • Không dùng dấu cách, ký tự đặc biệt
  • Không dùng từ khóa SQL (SELECT, FROM...)
  • Tên có ý nghĩa, đọc là hiểu ngay

Tránh lỗi khi chạy lại

CREATE TABLE IF NOT EXISTS nhan_vien (
    ...
);

Nếu bảng đã tồn tại → bỏ qua, không báo lỗi.

📊 Excel tương đương

Tạo sheet mới → đặt tên header cho từng cột → quy định loại dữ liệu mỗi cột (Data Validation).

🔒 Ràng Buộc (Constraints) — Phần 1

Quy tắc bắt buộc áp đặt lên cột — PostgreSQL tự động kiểm tra và từ chối vi phạm.

🔑 PRIMARY KEY — Khóa Chính

id  SERIAL  PRIMARY KEY
  • Mỗi bảng chỉ có một PRIMARY KEY
  • Giá trị phải duy nhất — không trùng
  • Giá trị không được NULL
  • Tự tạo index → tìm kiếm rất nhanh
-- Trùng id → Lỗi!
INSERT ... VALUES (1, 'Mai');
INSERT ... VALUES (1, 'An'); ← ❌ duplicate key

📊 Excel: Cột "Mã NV" không ai được trùng — nhưng Excel không tự kiểm tra!

🚫 NOT NULL — Bắt Buộc Có Giá Trị

ho_ten  VARCHAR(100)  NOT NULL
  • Cột bắt buộc phải có giá trị khi INSERT
  • Không truyền giá trị → báo lỗi
-- Không có ho_ten → Lỗi!
INSERT INTO nhan_vien (phong_ban)
VALUES ('IT');
-- ❌ null value violates not-null

📌 Mặc định: Không khai báo gì → cột được phép NULL (có thể để trống).

📊 Excel: Ô bôi đỏ trong form — "trường bắt buộc".

🔒 Ràng Buộc (Constraints) — Phần 2

🔐 UNIQUE

Giá trị không được trùng

email VARCHAR(150) UNIQUE
  • Mỗi giá trị xuất hiện tối đa 1 lần
  • Cho phép nhiều NULL
  • Một bảng có thể có nhiều UNIQUE

📊 Excel: COUNTIF($A:$A,A1)=1

📋 DEFAULT

Giá trị mặc định

dang_lam BOOLEAN
  DEFAULT TRUE,
ngay_vao TIMESTAMP
  DEFAULT NOW()
  • Không truyền giá trị → tự dùng DEFAULT
  • Có thể là: hằng số, hàm, biểu thức

📊 Excel: Ô đã có sẵn giá trị

✅ CHECK

Ràng buộc điều kiện tùy chỉnh

luong NUMERIC(12,2)
  CHECK (luong >= 0),
diem  INTEGER
  CHECK (diem BETWEEN
        1 AND 5)
  • Điều kiện sai → từ chối
  • Không thể bỏ qua

📊 Excel: Custom Formula validation

🔗 FOREIGN KEY — Khóa Ngoại (Giới thiệu)

phong_ban_id INTEGER REFERENCES phong_ban(id)

Đảm bảo giá trị tồn tại trong bảng khác. Sẽ học chi tiết ở Tuần 7 (JOIN).

📊 Excel: Giống VLOOKUP kiểm tra giá trị có tồn tại trong danh sách tham chiếu không.

🏗️ Ví Dụ CREATE TABLE Hoàn Chỉnh

Bảng nhan_vien

CREATE TABLE nhan_vien (
  id        SERIAL         PRIMARY KEY,
  ho_ten    VARCHAR(100)   NOT NULL,
  phong_ban VARCHAR(50),
  luong     NUMERIC(12,2)  CHECK (luong >= 0),
  ngay_sinh DATE,
  email     VARCHAR(150)   UNIQUE,
  ngay_vao  DATE           DEFAULT CURRENT_DATE,
  dang_lam  BOOLEAN        DEFAULT TRUE
);

Bảng san_pham

CREATE TABLE san_pham (
  id           SERIAL         PRIMARY KEY,
  ten_sp       VARCHAR(200)   NOT NULL,
  danh_muc     VARCHAR(100),
  gia          NUMERIC(12,2)  NOT NULL
               CHECK (gia > 0),
  so_luong_ton INTEGER        NOT NULL
               DEFAULT 0
               CHECK (so_luong_ton >= 0),
  mo_ta        TEXT,
  ngay_nhap    DATE           DEFAULT CURRENT_DATE,
  con_ban      BOOLEAN        DEFAULT TRUE
);

💡 Mẫu chung: id SERIAL PRIMARY KEY + các cột nghiệp vụ + ngay_vao DEFAULT + dang_lam BOOLEAN DEFAULT TRUE

Cú pháp — INSERT một hàng

INSERT INTO ten_bang (cot_1, cot_2, cot_3)

-- Ví dụ thực tế:
INSERT INTO nhan_vien

📏 Lưu ý quan trọng

  • Thứ tự cột phải khớp với thứ tự VALUES
  • Chuỗi & ngày: dấu nháy đơn '...'
  • Số: không cần dấu nháy
  • Cột có DEFAULT → có thể bỏ qua

📊 So sánh Excel

Giống gõ dữ liệu vào từng hàng trong sheet — nhưng PostgreSQL kiểm tra kiểu dữ liệu trước khi chấp nhận.

⚠️ Luôn khai báo rõ tên cột! Không dùng INSERT INTO ten_bang VALUES (...) vì dễ nhầm và dễ hỏng khi thêm cột mới.

📥 INSERT Nhiều Hàng & RETURNING

INSERT nhiều hàng cùng lúc

INSERT INTO nhan_vien
  (ho_ten, phong_ban, luong, ngay_sinh, email)
VALUES
  ('Trần Thị Mai',   'Kế toán',
   15000000, '1995-03-20', 'mai@cty.com'),
  ('Nguyễn Văn An',  'Kinh doanh',
   20000000, '1990-07-15', 'an@cty.com'),
  ('Lê Thị Bình',    'Nhân sự',
   18000000, '1992-11-03', 'binh@cty.com'),
  ('Hoàng Thị Dung', 'Kế toán',
   13000000, '1996-09-10', NULL);

💡 Multi-row INSERT nhanh hơn nhiều so với INSERT từng hàng — đặc biệt khi nhập hàng nghìn dòng.

INSERT với RETURNING

INSERT INTO nhan_vien
  (ho_ten, phong_ban, luong)
VALUES
  ('Nguyễn Mới', 'IT', 18000000)
RETURNING id, ho_ten;

Kết quả trả về:

 id |   ho_ten
----+-------------
  7 | Nguyễn Mới

Hữu ích khi cần biết id (SERIAL) vừa được tạo ra!

→

id = 7

🐛 Lỗi INSERT Thường Gặp

Thông báo lỗi Nguyên nhân Ví dụ
null value violates not-null constraint Bỏ qua cột có NOT NULL Không nhập ho_ten
invalid input syntax for type date Sai format ngày '20/03/1995' thay vì '1995-03-20'
duplicate key value violates unique constraint Trùng UNIQUE / PRIMARY KEY Nhập email đã tồn tại
new row violates check constraint Vi phạm CHECK Nhập luong = -1
value too long for type character varying(n) Chuỗi quá dài Vượt quá VARCHAR(100)

💡 Mẹo đọc lỗi: PostgreSQL luôn nói rõ cột nào và constraint nào bị vi phạm — đọc kỹ thông báo lỗi là biết cách sửa!

3.4

NULL — Ô Trống Đặc Biệt

⚠️ NULL là gì?

"Không có giá trị" — không biết, chưa xác định.

NULL ≠ số 0

NULL ≠ chuỗi rỗng ''

NULL = trạng thái thiếu dữ liệu

📊 So sánh Excel

Trạng tháiExcelPostgreSQL
Có số 000
Ô trống(trống)NULL
Khoảng trắng' '' '

Ví dụ thực tế:

Không có email→ email = NULL
Chưa có lương→ luong = NULL
Giá 0 đồng (free)→ gia = 0 (không phải NULL!)

❌ SAI — Không dùng = NULL

WHERE email = NULL    ← Luôn rỗng! ❌

✅ ĐÚNG — Dùng IS NULL

WHERE email IS NULL     ← ✅
WHERE email IS NOT NULL ← ✅

🔢 NULL Trong Phép Tính

Bất kỳ phép tính nào với NULL → NULL

SELECT 5 + NULL;
-- → NULL  (không phải 5!)

SELECT NULL * 100;
-- → NULL

SELECT 'Xin chào' || NULL;
-- → NULL  (không phải 'Xin chào')

📊 Excel: Ô trống trong công thức = 0 (Excel tự xử lý).

PostgreSQL: NULL vẫn là NULL — không tự chuyển!

Hàm tổng hợp & NULL

-- AVG() tự BỎ QUA NULL
SELECT AVG(luong) FROM nhan_vien;
-- Chỉ tính trên hàng có luong ✅

-- COUNT(*) đếm CẢ hàng có NULL
SELECT COUNT(*) FROM nhan_vien;
-- → 6 (kể cả email = NULL)

-- COUNT(cot) bỏ qua NULL
SELECT COUNT(email) FROM nhan_vien;
-- → 5 (bỏ hàng email = NULL)

💡 NULL = NULL luôn là UNKNOWN — vì "không biết" có bằng "không biết" không? Không thể biết!

🛡️ COALESCE & NULLIF — Xử Lý NULL

COALESCE() — Thay thế NULL

📊 Excel: IFERROR() hoặc IF(ISBLANK(...))

-- Thay NULL bằng giá trị mặc định
SELECT
    ho_ten,
    COALESCE(email, 'Chưa có email')
      AS email_hien_thi
FROM nhan_vien;
-- Tránh NULL trong tính toán
SELECT
    ho_ten,
    COALESCE(luong, 0) * 12
      AS thu_nhap_nam
FROM nhan_vien;
-- Nhiều tham số → lấy cái đầu tiên ≠ NULL
COALESCE(NULL, NULL, 'Thứ 3', 'Thứ 4')
-- → 'Thứ 3'

NULLIF() — Chuyển thành NULL

Nếu 2 giá trị bằng nhau → trả NULL

-- Tránh lỗi chia cho 0
SELECT 100 / NULLIF(so_luong, 0);
-- so_luong = 0 → NULL → 100/NULL = NULL ✅
-- so_luong = 5 → 5    → 100/5 = 20 ✅
-- Chuỗi rỗng '' coi như NULL
SELECT NULLIF(ghi_chu, '')
  AS ghi_chu_sach;
-- '' → NULL
-- 'Ghi chú thật' → 'Ghi chú thật'

3.5

Chỉnh Sửa Bảng — ALTER TABLE (Phần 1)

📊 Excel: Thêm/xóa cột trong sheet — nhưng cần thận trọng vì có dữ liệu hiện có.

➕ Thêm cột — ADD COLUMN

ALTER TABLE nhan_vien
  ADD COLUMN so_dien_thoai VARCHAR(20);

-- NOT NULL phải có DEFAULT:
ALTER TABLE nhan_vien
  ADD COLUMN ma_nv VARCHAR(10)
  NOT NULL DEFAULT 'NV000';

💡 Thêm cột NOT NULL vào bảng đã có dữ liệu → bắt buộc có DEFAULT (PostgreSQL không biết điền gì vào hàng cũ).

➖ Xóa cột — DROP COLUMN

ALTER TABLE nhan_vien
  DROP COLUMN so_dien_thoai;

-- An toàn hơn:
ALTER TABLE nhan_vien
  DROP COLUMN IF EXISTS so_dien_thoai;

⚠️ CẢNH BÁO: DROP COLUMN xóa vĩnh viễn cột và toàn bộ dữ liệu trong cột đó!

ALTER TABLE (Phần 2) — Đổi Tên, Kiểu & Constraints

✏️ Đổi tên cột/bảng

-- Đổi tên cột:
ALTER TABLE nhan_vien
  RENAME COLUMN ho_ten
  TO ten_day_du;

-- Đổi tên bảng:
ALTER TABLE nhan_vien
  RENAME TO nhan_su;

🔄 Đổi kiểu dữ liệu

ALTER TABLE nhan_vien
  ALTER COLUMN phong_ban
  TYPE VARCHAR(100);

⚠️ Đổi kiểu có thể thất bại nếu dữ liệu hiện tại không tương thích.

🔒 Thêm/Xóa Constraint

-- Thêm NOT NULL:
ALTER TABLE nhan_vien
  ALTER COLUMN phong_ban
  SET NOT NULL;

-- Bỏ NOT NULL:
ALTER TABLE nhan_vien
  ALTER COLUMN phong_ban
  DROP NOT NULL;
3.6

Xóa Bảng — DROP TABLE & TRUNCATE

💣 DROP TABLE

DROP TABLE ten_bang;
DROP TABLE IF EXISTS ten_bang;

Xóa vĩnh viễn cấu trúc + dữ liệu.

📊 = Xóa cả file Excel

🧹 TRUNCATE

TRUNCATE TABLE ten_bang;

-- Reset SERIAL về 1:
TRUNCATE TABLE ten_bang
  RESTART IDENTITY;

Xóa dữ liệu, giữ cấu trúc.

📊 = Xóa nội dung, giữ header

🔍 DELETE

DELETE FROM ten_bang
WHERE dieu_kien;

Xóa từng hàng theo điều kiện.

(Sẽ học ở Tuần 9)

  AND table_type = 'BASE TABLE';
