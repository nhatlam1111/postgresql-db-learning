Chương trình này được thiết kế riêng cho người có kỹ năng Excel tốt nhưng chưa từng học lập trình.

📊

Kỹ năng Excel tốt

Biết dùng VLOOKUP, Pivot Table, công thức lồng nhau — bạn đã hiểu logic phân tích dữ liệu.

🚫

Không cần biết code

SQL không phải ngôn ngữ lập trình. Nó gần với tiếng Anh tự nhiên và dễ đọc hơn công thức Excel phức tạp.

🔍

Thích chi tiết & chính xác

Database yêu cầu độ chính xác cao — chính là thế mạnh của những ai quen với báo cáo và phân tích số liệu.

⏱️

Học theo tốc độ của bạn

Mỗi tuần 3–5 giờ tự học. Mỗi bài có lý thuyết, ví dụ chạy được, và bài tập thực hành.

Mỗi Tuần Gồm 3 Bước

Tài liệu được tổ chức thành 3 loại file rõ ràng — bạn biết cần làm gì tiếp theo.

1

📖 Đọc bài học

File *_exercises.md — Tự viết SQL từ đầu. Ba cấp độ: Cơ bản → Trung bình → Nâng cao.

Excel ↔ PostgreSQL — Học Nhanh Qua Công Cụ Bạn Đã Biết

Mỗi khái niệm SQL đều có một thao tác Excel tương đương. Đây là cầu nối giúp bạn học nhanh hơn.

📊 Excel 🐘 PostgreSQL Ý nghĩa
Workbook (.xlsx)DATABASENơi chứa toàn bộ dữ liệu
Sheet (worksheet)TABLEMột tập dữ liệu có cấu trúc
Cột (A, B, C…)COLUMNMột loại thông tin
Hàng (1, 2, 3…)ROW / RECORDMột bản ghi dữ liệu
Data ValidationDATA TYPE + CONSTRAINTQuy định loại giá trị được nhập
FilterWHERELọc dữ liệu theo điều kiện
SortORDER BYSắp xếp kết quả
VLOOKUP / INDEX-MATCHJOINKết nối dữ liệu từ nhiều bảng
Pivot TableGROUP BYTổng hợp dữ liệu theo nhóm
SUM(), AVERAGE()SUM(), AVG()Hàm tính tổng, trung bình
IF() / IFS()CASE WHENĐiều kiện phân nhánh
Remove DuplicatesDISTINCTLoại bỏ giá trị trùng
IFERROR()COALESCE()Xử lý giá trị trống / lỗi
Named formula / pivot đã lưuVIEWTruy vấn được lưu lại, dùng lại
